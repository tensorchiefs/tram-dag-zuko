tramdag — Interpretable Neural Causal Models (TRAM-DAGs) in PyTorch

⚠️ Status: beta (0.x), under active development. The API may change between releases until 1.0; pin a version (tramdag==0.3.*) for reproducibility.

TRAM-DAGs model each variable of a structural causal model with a (transformation-model) flow: one triangular normalizing flow from iid standard-logistic latents to the observed variables. The triangular adjacency structure is exactly your causal DAG. Fit it once on observational data and answer all three rungs of Pearl's causal hierarchy — observational (L1), interventional (L2, the do-operator), and counterfactual (L3, Pearl abduction) — while keeping interpretable effects: every linear-shift coefficient is a log-odds ratio, exactly as in classical proportional-odds models.

Beate Sick & Oliver Dürr, Interpretable Neural Causal Models with TRAM-DAGs, CLeaR 2025 (arXiv:2503.16206). This repo is the reference implementation (PyTorch, built on zuko); all of the paper's experiments are replicated here with pinned tests.

5-minute showcase: the Colab badge above fits the paper's bimodal benchmark live (GPU-ready) and walks L1 → L2 → L3, every answer checked against analytic ground truth. Further notebooks are available at notebooks/ like the didactic walkthrough of the model: notebooks/intro_tram_dag.py.

import tramdag as td
from tramdag import CausalFlowDAG, ContinuousNode, OrdinalNode, I, LS, CS

spec = {  # the spec IS the labelled DAG
    "Age": ContinuousNode(),
    "mRS_pre": OrdinalNode(6, I("Age")),
    "NIHSSa": ContinuousNode(I("Age") + LS("mRS_pre")),
    "T": OrdinalNode(2, I("Age") + LS("mRS_pre") + CS("NIHSSa")),
    "mRS_3m": OrdinalNode(7, I("Age") + LS("mRS_pre") + CS("NIHSSa") + LS("T")),
}
flow = CausalFlowDAG(spec)  # validates acyclicity, builds the flow

# self-stopping training: per-node plateau lr decay + freezing of converged
# nodes (exact, since the per-node NLLs have independent gradients);
# see docs/training-speed.md for benchmarks and the classic two-phase recipe
flow.fit(
    train_df,
    val_df,
    epochs=4000,
    learning_rate=1e-2,
    batch_size=512,
    schedule="plateau",
    plateau_patience=30,
    freeze_patience=120,
)

# all-`ls` model? fit it classically instead: deterministic float64 L-BFGS,
# exact MLE matching statsmodels/R (see docs/fitting.md)
flow.fit_classical(train_df)  # raises on cs/ci specs

flow.log_prob(df)  # L1: joint log-likelihood per row
flow.sample(1000)  # L1: observational sampling
flow.sample(1000, do={"T": 1})  # L2: interventional (graph mutilation)
flow.pmf(df, node="mRS_3m", do={"T": 1})  # L2: analytic interventional PMF

u = flow.abduct(df)  # L3 step 1: latents from observations
cf = flow.sample(do={"T": 1}, u=u)  # L3 steps 2+3: counterfactuals

flow.ls_coefficients()  # interpret: per-edge log-odds-ratios
flow.intercept_contributions("NIHSSa", df)  # interpret: per-parent partial effects
# of an additive complex intercept (centered)

# heterogeneous treatment effects: a small, penalized effect head beta(x)*T
# (VC term) with a first-class read-out — see docs/varying-coefficients.md
# e.g. CS("Age", "NIHSSa") + VC("Age", t="T") ->
# flow.varying_coef("mRS_3m", df)          # beta(x): deterministic, y-free

flow.scores(df, node="mRS_3m")  # per-observation scores dl_i/dtheta
flow.effect_modifier_scan(df, "mRS_3m", t="T")  # which VC modifiers? (CUSUM
# scan from a cheap all-ls fit) — docs/scores.md

flow.save("flow.pt")

The model in detail: spec → math → networks

Per node, the transformation is additive on the latent (log-odds) scale — one intercept term I plus any number of shifts (notation: docs/notation.md):

u = h_ϑ(x) + Σ β·x_pa + Σ g(x_pa) + (β₀ + b_Θ(x_mod))·x_t

term math what gets built interpretability
I() / bare I / omitted h_ϑ(x) — constant ϑ SimpleIntercept: one free parameter vector, no network the baseline transform
I("A") h_ϑ(a)(x) — ϑ bends with the parent ComplexIntercept: MLP [8, 8] → n_params the parent reshapes the whole distribution; no single coefficient
I("A","B") (default allow_interaction=True) h_ϑ(a,b)(x) one joint MLP over both parents — they interact in ϑ maximal flexibility
I("A","B", allow_interaction=False) h_ϑ(a)+ϑ(b)(x) one MLP per parent, parameter vectors summed in coefficient space per-parent partial effects via flow.intercept_contributions
LS("A") β·a Linear(width, 1), no bias — one parameter exp(β) is an odds ratio
CS("A") g(a), additive ComplexShift: MLP [64, 128, 64] → 1 plot g
CS("A","B") g(a,b) — joint one MLP over the concatenated features interaction in the shift
CS("A") + CS("B") g₁(a) + g₂(b) two MLPs, scalars added GAM-style, each effect plottable
VC("A","B", t="T") (β₀ + b_Θ(a,b))·x_t scalar β₀ + zero-initialised penalized MLP [16] → 1; the treatment value multiplies, it never enters the net β₀ ≈ constant effect, flow.varying_coef reads β(x)

A node takes at most one I term with parents — a term list is therefore always purely additive on the latent scale, and interactions exist only inside a term. Lists and + sums are interchangeable: [LS("A"), CS("B")] ≡ LS("A") + CS("B").

Two knobs on the terms:

  • transform= on I picks the basis of h_ϑ for a continuous node — "bernstein" (default, 20 coefficients, tails extrapolate with the boundary slope), "spline" (monotone RQ spline, 23 params at bins=8, fixed tail slope) or "affine" (2 params: the latent is exactly logistic). Ordinal nodes have no basis: their intercept is the cutpoint vector, P(x ≤ k) = σ(ϑ_k − shift).
  • units= on I/CS/VC sizes the term's network, e.g. units=[16] for one hidden layer of 16 neurons (defaults above match the original Keras implementation, so fits stay comparable).

Feature widths: a continuous parent enters raw (1 column), an ordinal parent one-hot (levels columns). Abduction is exact for continuous nodes and truncated-logistic for ordinal ones, so flow.sample(u=flow.abduct(df)) reproduces df exactly / level-exactly.

There are two ways to fit the model: a stochastic deep learning optimizer (fit) and a 2nd order optimization like in the classical statistical models (fit_classical). The latter is more efficient for all-ls models (each node-conditional is then a classical transformation model). For more details, see the docs/fitting.md file.

Validation (all pinned by tests)

  • Paper replication — each of the paper's four DGP families has a generator in the registry (numpy-only SCM + frozen CSVs + replication script) and is pinned by tests:

    family paper demonstrates
    triangle (linear,atan,sin) §6.1 LS coefficient recovery (β = 2, −0.2, +0.3), CS curve ≡ −f(x₂), non-monotone f
    triangle-mixed (linear,exp) §6.2 mixed data L1/L2 + the C.4 odds-ratio check (OR ≈ 7.4)
    vaca §5.1–5.2 the bimodal L1 case a default CNF misses; L2 p(x₃ | do(x₂))

 341    # ------------------------------------------- centered-VC propensity (e_hat)
 342    def _vc_ehat_live(
 343        self, nd: _Node, values: dict[str, Tensor], n: int
 344    ) -> dict[str, Tensor] | None:
 345        """Recompute ``e_hat(pa_on) = P(on = 1 | pa_on)`` for the centered VC terms.
 346
 347        The value comes from this flow's own fitted ``on`` node, as a full-data
 348        propensity fit. That is the DML prediction convention. Training uses
 349        frozen out-of-fold values instead, see :meth:`fit`.
 350
 351        The result is detached, so no gradient reaches the ``on`` node from the
 352        loss of this node.
 353
 354        The function derives the value from the current parent values, so
 355        ``do``-mutilated sampling uses ``t - e_hat(x)`` with the intervened ``t``
 356        and the observed ``x``. It never reads a cached value.
 357        """
 358        out = {}
 359        for g in nd._vc_groups:
 360            if not g.center:
 361                continue
 362            on_nd = self.nodes[g.on]
 363            feats = self._features({p: values[p] for p in on_nd.parents})
 364            # chained centering is refused at fit time, so the treatment node
 365            # itself never has a centered term and needs no e_hat of its own
 366            theta, shift = on_nd.theta_shift(feats, n)
 367            # binary ordinal on: P(on <= 0) = sigmoid(theta_0 - s),
 368            # so e = sigmoid(s - theta_0)
 369            out[g.on] = torch.sigmoid(shift - theta[:, 0]).detach()
 370        return out or None

 372    def _vc_ehat_columns(self, nd: _Node) -> list[str]:

 375        These are the columns beyond ``nd.parents``: the parents of the
 376        treatment nodes (which cannot be centered themselves, so one level
 377        is all there is).
 378        """

 383    def node_log_prob(
 384        self,
 385        values: dict[str, Tensor],
 386        nodes: list[str] | None = None,
 387        vc_ehat: dict[str, dict[str, Tensor]] | None = None,
 388    ) -> dict[str, Tensor]:
 389        """Compute the per-node log-likelihood contributions.
 390
 391        Parameters
 392        ----------
 393        values : dict[str, Tensor]
 394            Raw node values, keyed by node name, each shape ``(n,)``.
 395        nodes : list[str] | None, optional
 396            Restrict the computation to these nodes. ``fit`` uses this to
 397            skip frozen nodes. That is valid because the per-node losses
 398            are independent. ``None`` (default) computes every node.
 399        vc_ehat : dict[str, dict[str, Tensor]] | None, optional
 400            Propensity override for centered VC terms, as
 401            ``{node: {on: e_hat}}``. ``fit`` passes the frozen
 402            **out-of-fold** values for the training rows. When omitted,
 403            the live full-fit propensity is recomputed from the flow's
 404            own treatment node.
 405
 406        Returns
 407        -------
 408        dict[str, Tensor]
 409            One log-likelihood tensor per node, each shape ``(n,)``.
 410        """
 411        feats = self._features(values)
 412        n = next(iter(values.values())).shape[0]
 413        out = {}
 414        for name in self.order if nodes is None else nodes:
 415            node = self.nodes[name]
 416            ehat = (
 417                vc_ehat.get(name)
 418                if vc_ehat is not None
 419                else self._vc_ehat_live(node, values, n)
 420            )
 421            theta, shift = node.theta_shift(feats, n, vc_ehat=ehat)
 422            x = values[name]
 423            if node.kind == "continuous":
 424                z0, ladj = node.ut.forward(theta, x)
 425                z = z0 + shift
 426                out[name] = StandardLogistic.log_prob(z) + ladj
 427            else:
 428                out[name] = ordinal_log_prob(theta, shift, x)
 429        return out

 504        self,
 505        train_df: pd.DataFrame,
 506        val_df: pd.DataFrame | None = None,
 507        epochs: int = 500,
 508        learning_rate: float = 1e-2,
 509        batch_size: int = 512,

 512        restore_best: bool = False,
 513        schedule: str | None = None,

 515        freeze_patience: int | None = None,
 516        min_delta: float = 1e-4,
 517        marginal_init: bool = False,
 518        vc_warm_start: bool = True,
 519        plateau_factor: float = 0.3,
 520        vc_oof_fit: dict | None = None,
 521    ) -> CausalFlowDAG:
 522        """Fit all nodes jointly by maximum likelihood.
 523
 524        By default training keeps the **final** (converged) weights. An
 525        all-``ls`` model trained to convergence then reproduces the classical
 526        maximum-likelihood estimate exactly, and matches ``statsmodels`` and
 527        R ``polr``.
 528
 529        The optimizer holds one parameter group per node. The joint NLL
 530        decomposes per node with independent gradients. Per-node learning
 531        rates and freezing are therefore exactly equivalent to independent
 532        per-node training.
 533
 534        A second ``fit`` call continues the training, for example a second
 535        phase with a lower learning rate. Freezing state does not carry
 536        across calls.
 537
 538        Parameters
 539        ----------
 540        train_df : pd.DataFrame
 541            Training data, one column per node.
 542        val_df : pd.DataFrame | None, optional
 543            Held-out set, used only for monitoring and for
 544            ``restore_best``, ``schedule="plateau"`` and
 545            ``freeze_patience``. If omitted, the training set supplies the
 546            validation metric.
 547        epochs : int, optional
 548            Number of training epochs, by default 500.
 549        learning_rate : float, optional
 550            Adam learning rate, by default 1e-2.
 551        batch_size : int, optional
 552            Minibatch size, by default 512.
 553        verbose : int, optional
 554            Print progress every ``verbose`` epochs, by default 50.
 555            0 turns the output off.
 556        seed : int | None, optional
 557            Seeds the minibatch shuffling only. Weight initialization
 558            happens at construction, see the class docstring.
 559        restore_best : bool, optional
 560            If True, snapshot each node's best-validation weights during
 561            training and restore them at the end. This is a mild
 562            early-stopping regularization and the convention of the
 563            original implementation. The snapshots persist on the model
 564            across ``fit`` calls, so a multi-phase fit restores the best
 565            epoch of *all* its phases; they are not saved in checkpoints.
 566            The fit is then *not* the training-data MLE, so leave it False
 567            for an exact classical comparison. Default False.
 568        schedule : str | None, optional
 569            ``None`` (default) keeps the learning rate constant.
 570            ``"plateau"`` decays **per node**: when the validation NLL of
 571            a node did not improve by ``min_delta`` for
 572            ``plateau_patience`` epochs, its learning rate decreases by
 573            ``plateau_factor``, with floor ``1e-3 * learning_rate``.
 574        plateau_patience : int, optional
 575            Epochs without improvement before one plateau decay step,
 576            by default 15.
 577        freeze_patience : int | None, optional
 578            If set, a node whose validation NLL did not improve by
 579            ``min_delta`` for this many epochs is **frozen** — excluded
 580            from the loss and the backward pass. This is a real compute
 581            saving, because the per-node losses are independent. When
 582            every node is frozen the fit returns early. Freeze epochs are
 583            recorded in ``history["frozen"]``. Under ``schedule="plateau"``
 584            a node freezes only after its learning rate decayed to
 585            ``1e-2 * learning_rate`` or below.
 586        min_delta : float, optional
 587            Smallest validation improvement that counts, by default 1e-4.
 588        marginal_init : bool, optional
 589            If True, calibrate the intercept of each *unconditional* node
 590            to its marginal at initialization, instead of zuko's default
 591            zero initialization. A Bernstein continuous node gets the
 592            linear map of the pre-scaled domain onto the standard-logistic
 593            5%/95% quantiles (the default is about 2.5x too steep). An
 594            ordinal node gets cutpoints at the empirical class log-odds
 595            (the default zeros are near-uniform). This is a pure
 596            initialization: the converged MLE is unchanged. Applied on the
 597            first fit only. Affects only ``SimpleIntercept`` nodes;
 598            conditional ``ci`` intercepts stay untouched. Default False.
 599        vc_warm_start : bool, optional
 600            If True (default), the ``beta0`` of each ``VC`` term is
 601            initialized from the classical all-``ls`` solution of its
 602            node's conditional (deterministic L-BFGS on a throwaway
 603            proxy). The penalized head then starts at the classical answer
 604            and only learns deviations. Applied once per term — a buffer
 605            that survives ``save``/``load`` guards against re-runs. Does
 606            nothing without VC terms.
 607        plateau_factor : float, optional
 608            Multiplier of one per-node plateau decay step, by default 0.3.
 609            Read only under ``schedule="plateau"``.
 610        vc_oof_fit : dict | None, optional
 611            Keyword overrides for the stage-1 out-of-fold proxy fits of
 612            centered VC terms, merged over the default
 613            ``{"epochs": 300, "learning_rate": 1e-2, "batch_size": 512}``.
 614            Ignored when the treatment node is all-``ls`` — the
 615            deterministic :meth:`fit_classical` runs instead.
 616
 617        Returns
 618        -------
 619        CausalFlowDAG
 620            ``self``, fitted.
 621
 622        Raises
 623        ------
 624        ValueError
 625            If ``schedule`` is not one of the four options.
 626
 627        Notes
 628        -----
 629        For ``VC`` terms the objective is the **penalized** NLL on the
 630        total-likelihood scale. Each term adds
 631        ``penalty * ||b_theta weights||^2`` to the summed NLL, that is
 632        ``penalty * ||w||^2 / n_train`` to the mean loss. This is a fixed
 633        Gaussian prior: the shrinkage vanishes as n grows, the classical
 634        penalized-likelihood convention. ``beta0`` is not penalized. The
 635        recorded ``history`` NLLs stay pure likelihoods. After training,
 636        each ``b_theta`` is re-centered to mean zero over the training
 637        data. That preserves the function: the constant moves into
 638        ``beta0``.
 639
 640        ``VC(center=...)`` terms run a stage-1 out-of-fold propensity
 641        computation before the loop (:meth:`_vc_oof_stage`). The training
 642        loss uses those frozen out-of-fold values. The epoch-level
 643        validation monitor, and every post-fit query, uses the live
 644        full-fit treatment node.
 645        """
 646        if schedule not in (None, "plateau"):
 647            raise ValueError(f"unknown schedule {schedule!r}")
 648        if seed is not None:
 649            torch.manual_seed(seed)
 650        self._set_ranges(train_df, marginal_init=marginal_init)
 651        if vc_warm_start:
 652            self._vc_warm_start(train_df)
 653        # VC effect heads whose L2 penalty joins the loss, per owning node
 654        vc_penalized = {
 655            name: [
 656                self.nodes[name].shifts[g.on]
 657                for g in self.nodes[name]._vc_groups
 658                if g.mods and self.nodes[name].shifts[g.on].penalty > 0
 659            ]
 660            for name in self.order
 661        }
 662        # stage 1 for centered VC terms (issue #30): frozen OUT-OF-FOLD e_hat
 663        # for the training rows — a plain tensor, so the Y-node loss has no
 664        # gradient path into the treatment node (per-node factorization intact).
 665        vc_ehat_train = self._vc_oof_stage(train_df, vc_oof_fit)
 666
 667        train_vals = self._tensorize(train_df)
 668        val_vals = self._tensorize(val_df) if val_df is not None else train_vals
 669        n = len(train_df)
 670
 671        opt = torch.optim.Adam(
 672            [
 673                {
 674                    "params": list(self.nodes[name].parameters()),
 675                    "lr": learning_rate,
 676                    "node": name,
 677                }
 678                for name in self.order
 679            ]
 680        )
 681        if restore_best and not hasattr(self, "_best"):
 682            self._best = {name: (float("inf"), None) for name in self.order}
 683        best = self._best if restore_best else None
 684        # per-node plateau/freeze bookkeeping (local to this fit call)
 685        node_best = {name: float("inf") for name in self.order}
 686        node_bad = dict.fromkeys(self.order, 0)
 687        frozen: set[str] = set()
 688        t0 = time.perf_counter()
 689        t_offset = self.history["time"][-1] if self.history.get("time") else 0.0
 690        prev_train: dict[str, float] = {}
 691
 692        for epoch in range(epochs):
 693            self.train()
 694            active = [name for name in self.order if name not in frozen]
 695            perm = torch.randperm(n, device=self.device)
 696            train_acc = {name: prev_train.get(name, float("nan")) for name in frozen}
 697            train_acc.update(dict.fromkeys(active, 0.0))
 698            for start in range(0, n, batch_size):
 699                idx = perm[start : start + batch_size]
 700                batch = {k: v[idx] for k, v in train_vals.items()}
 701                ehat_batch = (
 702                    None
 703                    if vc_ehat_train is None
 704                    else {
 705                        nm: {on: e[idx] for on, e in d.items()}
 706                        for nm, d in vc_ehat_train.items()
 707                    }
 708                )
 709                per_node = self.node_log_prob(batch, nodes=active, vc_ehat=ehat_batch)
 710                node_nlls = {k: -v.mean() for k, v in per_node.items()}
 711                loss = torch.stack(list(node_nlls.values())).sum()
 712                for name in active:  # VC penalty (excluded from history)
 713                    for m in vc_penalized[name]:
 714                        loss = loss + m.penalty * m.l2() / n
 715                opt.zero_grad()
 716                loss.backward()
 717                opt.step()
 718                w = len(idx) / n
 719                for k, v in node_nlls.items():
 720                    train_acc[k] += float(v.detach()) * w
 721            prev_train = train_acc
 722
 723            self.eval()
 724            with torch.no_grad():
 725                val_per_node = {
 726                    k: float(-v.mean()) for k, v in self.node_log_prob(val_vals).items()
 727                }
 728            self.history["train"].append(train_acc)
 729            self.history["val"].append(val_per_node)
 730            self.history["lr"].append(max(g["lr"] for g in opt.param_groups))
 731            self.history["time"].append(t_offset + time.perf_counter() - t0)
 732
 733            # per-node improvement tracking (plateau decay + freezing)
 734            for g in opt.param_groups:
 735                name = g["node"]
 736                if name in frozen:
 737                    continue
 738                if val_per_node[name] < node_best[name] - min_delta:
 739                    node_best[name] = val_per_node[name]
 740                    node_bad[name] = 0
 741                else:
 742                    node_bad[name] += 1
 743                if (
 744                    schedule == "plateau"
 745                    and node_bad[name] > 0
 746                    and node_bad[name] % plateau_patience == 0
 747                ):
 748                    g["lr"] = max(g["lr"] * plateau_factor, learning_rate * 1e-3)
 749                # under "plateau", only freeze nodes whose lr has already been
 750                # decayed substantially — otherwise a node can freeze while a
 751                # smaller lr would still make progress toward the optimum
 752                lr_decayed = schedule != "plateau" or g[
 753                    "lr"
 754                ] <= learning_rate * 1e-2 * (1 + 1e-9)
 755                if (
 756                    freeze_patience is not None
 757                    and lr_decayed
 758                    and node_bad[name] >= freeze_patience
 759                ):
 760                    frozen.add(name)
 761                    self.history.setdefault("frozen", {}).setdefault(
 762                        name, len(self.history["val"])
 763                    )  # 1-based global epoch
 764
 765            if restore_best:
 766                for name in self.order:
 767                    if val_per_node[name] < best[name][0]:
 768                        best[name] = (
 769                            val_per_node[name],
 770                            copy.deepcopy(self.nodes[name].state_dict()),
 771                        )
 772
 773            if verbose and (epoch % verbose == 0 or epoch == epochs - 1):
 774                tot_t = sum(train_acc.values())
 775                tot_v = sum(val_per_node.values())
 776                logger.info(
 777                    "[epoch %5d/%d] train NLL %.4f  val NLL %.4f%s",
 778                    epoch + 1,
 779                    epochs,
 780                    tot_t,
 781                    tot_v,
 782                    f"  frozen {sorted(frozen)}" if frozen else "",
 783                )
 784
 785            if len(frozen) == len(self.order):  # everything converged
 786                if verbose:
 787                    logger.info("[epoch %5d] all nodes frozen — stopping.", epoch + 1)
 788                break
 789
 790        if restore_best:  # restore per-node best-validation weights
 791            for name, (_, state) in best.items():
 792                if state is not None:
 793                    self.nodes[name].load_state_dict(state)
 794        self._recenter_vc(train_vals)
 795        self.eval()
 796        return self

 799    def _source_proxies(self, parents) -> dict[str, NodeSpec]:
 800        """Give a proxy spec whose parents are sources.
 801
 802        A single-node proxy only has to reproduce one conditional, which the
 803        parent marginals cannot influence — so each parent collapses to a
 804        source node of the right kind.
 805        """
 806        out: dict[str, NodeSpec] = {}
 807        for p in parents:
 808            pn = self.spec[p]
 809            out[p] = (
 810                OrdinalNode(pn.levels)
 811                if isinstance(pn, OrdinalNode)
 812                else ContinuousNode([I(transform="affine")])
 813            )
 814        return out

 816    def _vc_warm_start(self, train_df: pd.DataFrame) -> None:
 817        """Initialize every VC term's ``beta0`` from the classical solution.
 818
 819        The value comes from the all-``ls`` solution of the node's conditional.
 820        Issue #28 recommends this warm start.
 821
 822        A throwaway proxy of the node (same kind/transform, every parent an LS
 823        term, parent marginals irrelevant to the conditional because the joint
 824        NLL decomposes per node) is fitted with the deterministic
 825        :meth:`fit_classical`, and the ``on`` coefficient copied into ``beta0``
 826        (for a binary ordinal treatment, the identified one-hot difference
 827        ``w[1] - w[0]``). ``b_theta`` already starts at the zero function
 828        (zero-initialized output layer). Runs once per term — the
 829        ``warm_started`` buffer survives ``save``/``load``.
 830        """
 831        for name in self.order:
 832            nd = self.nodes[name]
 833            todo = [g for g in nd._vc_groups if not bool(nd.shifts[g[0]].warm_started)]
 834            if not todo:
 835                continue
 836            node_spec = self.spec[name]
 837            proxy_spec = self._source_proxies(nd.parents)
 838            ls_terms = [LS(p) for p in nd.parents]
 839            if isinstance(node_spec, OrdinalNode):
 840                proxy_spec[name] = OrdinalNode(node_spec.levels, ls_terms)
 841            else:
 842                proxy_spec[name] = ContinuousNode(
 843                    [
 844                        I(
 845                            transform=node_spec.transform,
 846                            **dict(node_spec.transform_kwargs),
 847                        ),
 848                        *ls_terms,
 849                    ]
 850                )
 851            proxy = CausalFlowDAG(proxy_spec, device=str(self.device))
 852            proxy.fit_classical(train_df[[*nd.parents, name]], verbose=False)
 853            for g in todo:
 854                w = proxy.nodes[name].shifts[g.on].weight.detach()
 855                b0 = float(w[-1] - w[0]) if g.on_is_ord else float(w[0])
 856                m = nd.shifts[g.on]
 857                with torch.no_grad():
 858                    m.beta0.fill_(b0)
 859                m.warm_started.fill_(True)

 861    @torch.no_grad()
 862    def _predict_p1(self, on: str, df: pd.DataFrame) -> np.ndarray:
 863        """Give ``P(on = 1 | pa_on)`` from this flow's ``on`` node.
 864
 865        The treatment is binary ordinal, so the value is
 866        ``sigmoid(shift - theta_0)``.
 867        """
 868        nd = self.nodes[on]
 869        values = self._tensorize(df, nd.parents)
 870        feats = self._features(values)
 871        theta, shift = nd.theta_shift(
 872            feats, len(df), vc_ehat=self._vc_ehat_live(nd, values, len(df))
 873        )
 874        return torch.sigmoid(shift - theta[:, 0]).cpu().numpy()

 876    def _vc_oof_stage(
 877        self, train_df: pd.DataFrame, vc_oof_fit: dict | None = None
 878    ) -> dict[str, dict[str, Tensor]] | None:
 879        """Compute stage 1 of the two-stage centered-VC design, issue #30.
 880
 881        The result holds the frozen training-time propensities, as
 882        ``{node: {on: (n,) tensor}}``.
 883
 884        The values are **out-of-fold** — K refits of the treatment node
 885        only, each predicting its held-out fold (the DML cross-fitting
 886        requirement; in-sample e_hat reintroduces the own-observation bias
 887        and can be worse than no centering). Bookkeeping lands in
 888        ``self.vc_center_info[(node, on)]`` (``e_oof``, ``fold_id``,
 889        ``folds``, ``n``) so tests can assert the fold structure — a later
 890        "simplification" to in-sample e_hat fails CI.
 891        """
 892        jobs = [
 893            (name, g)
 894            for name in self.order
 895            for g in self.nodes[name]._vc_groups
 896            if g.center
 897        ]
 898        if not jobs:
 899            return None
 900        self.vc_center_info = {}
 901        np_dtype = self._np_dtype
 902        out: dict[str, dict[str, Tensor]] = {}
 903        rng_state = torch.get_rng_state()  # proxies reseed; keep fit reproducible
 904        try:
 905            for name, g in jobs:
 906                e, fold_id = self._vc_oof_propensity(
 907                    g.on, train_df, g.folds, vc_oof_fit
 908                )
 909                out.setdefault(name, {})[g.on] = torch.as_tensor(
 910                    e.astype(np_dtype), device=self.device
 911                )
 912                self.vc_center_info[(name, g.on)] = {
 913                    "folds": int(g.folds),
 914                    "fold_id": fold_id,
 915                    "e_oof": e.copy(),
 916                    "n": len(train_df),
 917                }
 918        finally:
 919            torch.set_rng_state(rng_state)
 920        return out
 921
 922    def _vc_oof_propensity(
 923        self, on: str, train_df: pd.DataFrame, k: int, vc_oof_fit: dict | None = None
 924    ) -> tuple[np.ndarray, np.ndarray]:
 925        """Compute the out-of-fold ``P(on=1|pa_on)``.
 926
 927        The function refits the ``on`` node K times, and only that node. Each
 928        refit uses a single-node proxy whose parents are sources, because their
 929        marginals cannot influence the conditional. Each refit then predicts the
 930        fold it never saw.
 931
 932        A treatment with all-``ls`` terms uses :meth:`fit_classical`, which is
 933        deterministic and takes seconds. Any other treatment uses a
 934        fixed-budget Adam fit — ``vc_oof_fit`` overrides its keywords, see
 935        :meth:`fit`.
 936        """
 937        on_nd = self.nodes[on]
 938        if any(g.center for g in on_nd._vc_groups):
 939            raise NotImplementedError(
 940                f"treatment node {on!r} itself has a centered VC term. "
 941                "Chained centering is not supported."
 942            )
 943        node_spec = self.spec[on]
 944        proxy_spec = self._source_proxies(on_nd.parents)
 945        terms = node_terms(node_spec) or None
 946        proxy_spec[on] = OrdinalNode(2, terms)
 947        all_ls = all(t.effect == "LS" for t in (terms or []))
 948        cols = [*on_nd.parents, on]
 949
 950        n = len(train_df)
 951        fold_id = np.random.default_rng(0).permutation(n) % k
 952        e = np.empty(n, dtype=np.float64)
 953        for j in range(k):
 954            proxy = CausalFlowDAG(proxy_spec, device=str(self.device), seed=0)
 955            held_in = train_df.iloc[fold_id != j][cols]
 956            if all_ls:
 957                proxy.fit_classical(held_in, verbose=False)
 958            else:
 959                fit_kw = {"epochs": 300, "learning_rate": 1e-2, "batch_size": 512}
 960                fit_kw.update(vc_oof_fit or {})
 961                proxy.fit(held_in, verbose=0, seed=0, restore_best=False, **fit_kw)
 962            e[fold_id == j] = proxy._predict_p1(on, train_df.iloc[fold_id == j])
 963        return e, fold_id

 965    @torch.no_grad()
 966    def _recenter_vc(self, values: dict[str, Tensor]) -> None:
 967        """Re-split every VC term so ``b_theta`` sums to zero over the train rows.
 968
 969        The removed constant moves into ``beta0``, so the modelled function does
 970        not change.
 971        """
 972        feats: dict[str, Tensor] | None = None
 973        for name in self.order:
 974            nd = self.nodes[name]
 975            for g in nd._vc_groups:
 976                if not g.mods:
 977                    continue
 978                if feats is None:
 979                    feats = self._features(values)
 980                nd.shifts[g.on].recenter(torch.cat([feats[p] for p in g.mods], dim=1))

 982    @torch.no_grad()
 983    def varying_coef(
 984        self, node: str, data: pd.DataFrame, t: str | None = None
 985    ) -> np.ndarray:
 986        """Evaluate the fitted effect function ``beta(x)`` of a ``VC`` term.
 987
 988        This is the first-class read-out of issue #28. The value comes in
 989        closed form from the fitted term, as ``beta0 + b_theta(modifiers)``.
 990        It is deterministic and needs no abduction. It is free of ``y``,
 991        because only the modifier columns of ``data`` are read. For a binary
 992        treatment it is identical to the abduction difference
 993        ``u(x, t=1, y) - u(x, t=0, y)``.
 994
 995        The value lives on the latent, log-odds scale of the node. A
 996        continuous node adds it. An ordinal node subtracts it from the
 997        cutpoints.
 998
 999        For a centered term (``center=...``) the form of the returned
1000        ``beta`` does not change. ``beta0`` then reads as the effect at the
1001        treatment margin, which is the observed propensities.
1002
1003        Parameters
1004        ----------
1005        node : str
1006            Name of the node that carries the VC term.
1007        data : pd.DataFrame
1008            Rows at which to evaluate ``beta``. Must contain every modifier
1009            column of the term.
1010        t : str | None, optional
1011            Treatment name of the VC term. Optional when the node has
1012            exactly one VC term.
1013
1014        Returns
1015        -------
1016        np.ndarray
1017            The ``beta`` values, shape ``(n,)``. Constant when the term has
1018            no modifiers.
1019
1020        Raises
1021        ------
1022        KeyError
1023            If ``node`` is unknown, if the node has no VC term on ``t``, or
1024            if a modifier column is missing from ``data``.
1025        ValueError
1026            If the node has no VC term, or if ``t`` is omitted while the
1027            node has several VC terms.
1028        """
1029        nd = self._node(node)
1030        vcs = {g.on: g.mods for g in nd._vc_groups}
1031        if not vcs:
1032            raise ValueError(f"node {node!r} has no VC term.")
1033        if t is None:
1034            if len(vcs) > 1:
1035                raise ValueError(
1036                    f"node {node!r} has several VC terms ({sorted(vcs)}). "
1037                    "Pass on=<treatment name>."
1038                )
1039            t = next(iter(vcs))
1040        if t not in vcs:
1041            raise KeyError(
1042                f"node {node!r} has no VC term on {t!r} (has {sorted(vcs)})."
1043            )
1044        mods = vcs[t]
1045        missing = [p for p in mods if p not in data.columns]
1046        if missing:
1047            raise KeyError(f"data is missing modifier column(s): {missing}")
1048        mod_feat = None
1049        if mods:
1050            feats = self._features(self._tensorize(data, mods))
1051            mod_feat = torch.cat([feats[p] for p in mods], dim=1)
1052        return nd.shifts[t].beta(mod_feat, len(data)).cpu().numpy()
1053

1064    def ls_coefficients(self) -> dict[str, dict[str, np.ndarray]]:
1065        """Give the per-node linear-shift weights.
1066
1067        For an all-``ls`` model these are the interpretable log-odds-ratio
1068        coefficients.
1069
1070        Returns
1071        -------
1072        dict[str, dict[str, np.ndarray]]
1073            The weights, as ``{node: {parent: array}}``. A node without
1074            shift terms is absent.
1075        """

1077        for name in self.order:

1082                    for p, m in shifts.items()
1083                }
1084        return out

1086    def to_matrix(self) -> pd.DataFrame:
1087        """Give the labeled adjacency matrix of term effects.
1088
1089        This is the meta-adjacency view of the paper.
1090
1091        Returns
1092        -------
1093        pd.DataFrame
1094            Rows are parents and columns are children. A cell holds the
1095            term tag: ``"LS"``, ``"CS"``, ``"CI"``, ``"VC"`` for a VC
1096            treatment, or ``"VCm"`` for a VC modifier. An empty cell means
1097            there is no edge. A multi-parent term carries its parent group
1098            as a suffix. When several terms share a cell, their tags join
1099            with ``"+"``.
1100        """
1101        labels = {"I": "CI", "LS": "LS", "CS": "CS"}
1102        m = pd.DataFrame("", index=list(self.order), columns=list(self.order))
1103        for child in self.order:
1104            for term in node_terms(self.spec[child]):
1105                if term.effect == "VC":  # treatment cell "VC", modifiers "VCm"
1106                    cells = [(term.parents[0], "VC")] + [
1107                        (p, "VCm") for p in term.parents[1:]
1108                    ]
1109                else:
1110                    tag = labels[term.effect]
1111                    if len(term.parents) > 1:
1112                        tag = f"{tag}{list(term.parents)}"
1113                    cells = [(p, tag) for p in term.parents]
1114                for p, tag in cells:  # a VC modifier may share its cell with
1115                    cur = m.loc[p, child]  # a prognostic term -> join with "+"

1119    @torch.no_grad()
1120    def intercept_contributions(self, node: str, data: pd.DataFrame) -> dict:
1121        """Decompose a complex intercept into mean-centered per-term parts.
1122
1123        The parts are contributions to the transform parameters of the node.
1124        Use them to plot additive partial effects.
1125
1126        An additive complex intercept, ``[I("x1"), I("x2")]``, builds one
1127        network per ``I`` term and **sums their outputs in unconstrained
1128        parameter space**: ``theta(pa) = net_1(x1) + net_2(x2)``. The sum is
1129        identified, so every L1/L2/L3 query is correct. Each term's output,
1130        however, is identified only up to a constant — a constant moves
1131        freely between the nets. The *raw* per-term outputs are therefore
1132        not directly comparable.
1133
1134        This method resolves the ambiguity with the usual additive-model
1135        (GAM) convention: a **sum-to-zero (mean-centering) constraint over
1136        the rows of** ``data``. Each term's contribution is centered to mean
1137        zero per parameter. The removed constants collect into a single
1138        ``baseline``. The decomposition is exact:
1139
1140            ``theta(pa) = baseline + sum_terms contribution_term(pa)``
1141
1142        ``baseline`` plus the uncentered row sum of the contributions
1143        reproduces the model's transform parameters. This is **post-hoc
1144        only**: it reads the fitted weights and changes nothing about the
1145        model or any frozen number (issue #20, Option A). Shift terms
1146        (``LS``/``CS``) are a separate, already-interpretable slot — see
1147        :meth:`ls_coefficients`.
1148
1149        Parameters
1150        ----------
1151        node : str
1152            Name of a node with at least one complex-intercept (``I``) term
1153            that has parents.
1154        data : pd.DataFrame
1155            Rows over which to center and at which to evaluate the
1156            contributions. Must contain every intercept-parent column.
1157
1158        Returns
1159        -------
1160        dict
1161            Three keys. ``"baseline"`` is the absorbed constant, a ``(P,)``
1162            array — the sum of the per-term means. ``P`` is the node's
1163            transform-parameter count: ``ut.n_params`` for a continuous
1164            node, ``levels - 1`` cutpoint parameters for an ordinal node.
1165            ``"contributions"`` is ``{term_label: (n, P) array}`` — each
1166            term's mean-centered contribution at each row, columns summing
1167            to about zero over the rows. ``term_label`` is the term's
1168            parents joined by ``"+"``. ``"parents"`` is
1169            ``{term_label: tuple(parent_names)}``.
1170
1171        Raises
1172        ------
1173        KeyError
1174            If ``node`` is unknown, or if an intercept-parent column is
1175            missing from ``data``.
1176        ValueError
1177            If the node has no complex-intercept term with parents.
1178
1179        Notes
1180        -----
1181        The contributions live in the transform's **unconstrained**
1182        parameter space, where the model sums the additive terms before the
1183        monotonicity constraint. They are exact partial effects on those
1184        parameters, but not, in general, an additive shift of the curve
1185        itself.
1186        """
1187        nd = self._node(node)
1188        groups = nd._intercept_groups
1189        if not groups:
1190            raise ValueError(
1191                f"node {node!r} has no complex-intercept (I) terms with parents. "
1192                "Its intercept is unconditional, so there is nothing to decompose."
1193            )
1194        missing = [p for p in nd.ci_parents if p not in data.columns]
1195        if missing:
1196            raise KeyError(f"data is missing intercept-parent column(s): {missing}")
1197
1198        feats = self._features(self._tensorize(data, nd.ci_parents))
1199        # one net per group: the additive case stores them in intercept_nets;
1200        # a single (possibly joint) I-term is the lone `intercept` network.
1201        nets = (
1202            list(nd.intercept_nets) if nd.intercept_nets is not None else [nd.intercept]
1203        )
1204
1205        contributions: dict[str, np.ndarray] = {}
1206        parents: dict[str, tuple] = {}
1207        baseline = None
1208        for net, grp in zip(nets, groups, strict=True):
1209            raw = net(torch.cat([feats[p] for p in grp], dim=1))  # (n, P)
1210            mean = raw.mean(dim=0, keepdim=True)  # (1, P)
1211            label = "+".join(grp)
1212            contributions[label] = (raw - mean).cpu().numpy()
1213            parents[label] = grp
1214            baseline = mean if baseline is None else baseline + mean
1215        return {
1216            "baseline": baseline.cpu().numpy().ravel(),
1217            "contributions": contributions,
1218            "parents": parents,
1219        }

1221    @torch.no_grad()
1222    def design_matrix(
1223        self, df: pd.DataFrame, node: str, *, drop_first: bool = False
1224    ) -> pd.DataFrame:
1225        """Encode a node's parents the way the flow feeds them to its shifts.
1226
1227        A continuous parent stays raw in one column named after it. An
1228        ordinal parent becomes one column per level, named
1229        ``"{parent}[{k}]"`` — the same one-hot the flow builds internally.
1230
1231        Use ``drop_first=True`` to get the design a classical reference
1232        expects (``statsmodels`` ``OrderedModel``, R ``polr``): with
1233        cutpoints the full one-hot is unidentified, so each ordinal parent's
1234        level-0 column drops out and its remaining coefficients read as
1235        differences against level 0 — exactly what ``w[k] - w[0]`` gives on
1236        the flow side.
1237
1238        Parameters
1239        ----------
1240        df : pd.DataFrame
1241            Rows to encode. Must contain every parent column of ``node``.
1242        node : str
1243            Name of the node whose parents are encoded.
1244        drop_first : bool, optional
1245            Drop each ordinal parent's level-0 column, by default ``False``.
1246
1247        Returns
1248        -------
1249        pd.DataFrame
1250            One column per encoded feature, indexed like ``df``.
1251        """
1252        nd = self._node(node)
1253        feats = self._features(self._tensorize(df, nd.parents))
1254        cols: dict[str, np.ndarray] = {}
1255        for p in nd.parents:
1256            arr = feats[p].cpu().numpy()
1257            if arr.shape[1] == 1:  # continuous parent: raw
1258                cols[p] = arr[:, 0]
1259            else:
1260                for k in range(1 if drop_first else 0, arr.shape[1]):
1261                    cols[f"{p}[{k}]"] = arr[:, k]
1262        return pd.DataFrame(cols, index=df.index)

1264    def fit_classical(
1265        self,
1266        train_df: pd.DataFrame,
1267        *,
1268        max_iter: int = 400,
1269        tol: float = 1e-6,
1270        chunk: int = 25,
1271        history_size: int = 50,
1272        verbose: bool = True,
1273    ) -> dict:
1274        """Fit an all-``ls`` model the classical way.
1275
1276        The fit uses full batches, float64, and L-BFGS with a strong-Wolfe
1277        line search. There are no minibatches, no schedule and no early
1278        stopping, so the fit is deterministic and bit-reproducible. It lands
1279        on the exact maximum-likelihood estimate and matches classical
1280        software, that is ``statsmodels`` ``OrderedModel`` and R ``polr`` or
1281        ``Colr``. It is much faster than minibatch Adam.
1282
1283        This method is valid only when every edge is ``ls``, because each
1284        node-conditional is then a classical transformation model. Any other
1285        model raises. For a ``cs`` or ``ci`` model use :meth:`fit`, where
1286        the minibatch noise also regularizes the MLPs.
1287
1288        Parameters
1289        ----------
1290        train_df : pd.DataFrame
1291            Training data, one column per node.
1292        max_iter : int, optional
1293            Upper limit on L-BFGS iterations, by default 400.
1294        tol : float, optional
1295            Relative NLL change between L-BFGS rounds that counts as
1296            converged, by default 1e-6.
1297        chunk : int, optional
1298            Inner L-BFGS iterations per round, by default 25. Convergence
1299            is checked between rounds.
1300        history_size : int, optional
1301            L-BFGS memory, by default 50.
1302        verbose : bool, optional
1303            Print a one-line summary, by default True.
1304
1305        Returns
1306        -------
1307        dict
1308            A convergence report: ``converged``, ``n_iter``, ``final_nll``,
1309            ``grad_norm``, ``coef_delta`` (largest coefficient change at
1310            the last round), ``seconds``, and the fitted ``coefficients``
1311            from :meth:`ls_coefficients`.
1312
1313        Raises
1314        ------
1315        ValueError
1316            If the spec has ``cs``, ``ci`` or ``vc`` terms.
1317
1318        Notes
1319        -----
1320        float64 is a transient compute mode. The model is upcast for the
1321        fit, and ``self.double()`` converts the parameters and the range
1322        buffers of the transforms in one call. Afterwards the model returns
1323        to float32, so the stored model and ``save``/``load`` stay float32.
1324        Double precision is what lets the line search resolve the optimum
1325        cleanly.
1326
1327        Convergence is judged by **NLL flatness**: a relative change below
1328        ``tol`` between L-BFGS rounds. ``|grad|`` and individual
1329        coefficients do *not* settle to machine precision. A continuous
1330        node's Bernstein intercept, and weakly-identified directions such
1331        as rare one-hot levels or a flat treatment-effect ridge, keep
1332        drifting along near-zero-curvature valleys long after the
1333        likelihood and the well-identified coefficients reach the MLE.
1334        Correctness is therefore verified by comparison to classical
1335        software (see ``experiments/validate_ls.py``), not by this flag.
1336        """
1337        if not self._is_all_ls():
1338            raise ValueError(
1339                "fit_classical requires an all-`ls` spec, that is every edge "
1340                "term 'ls'. This spec has cs, ci or vc terms. Use fit() for "
1341                "flexible models."
1342            )
1343        self._set_ranges(train_df)
1344
1345        self.double()  # parameters + buffers (xmin/xmax) -> float64, one call
1346        assert next(self.parameters()).dtype == torch.float64
1347        t0 = time.perf_counter()
1348        # chunk: inner L-BFGS iterations per round; we stop on NLL change
1349        try:
1350            vals = self._tensorize(train_df)
1351            self.train()
1352            opt = torch.optim.LBFGS(
1353                self.parameters(),
1354                lr=1.0,
1355                max_iter=chunk,
1356                history_size=history_size,
1357                tolerance_grad=0.0,
1358                tolerance_change=0.0,
1359                line_search_fn="strong_wolfe",
1360            )
1361
1362            def closure():
1363                opt.zero_grad()
1364                nll = torch.stack(
1365                    [-lp.mean() for lp in self.node_log_prob(vals).values()]
1366                ).sum()
1367                nll.backward()
1368                return nll
1369
1370            def flat_coefs() -> np.ndarray:
1371                cs = self.ls_coefficients()
1372                return (
1373                    np.concatenate([w for node in cs.values() for w in node.values()])
1374                    if cs
1375                    else np.zeros(1)
1376                )
1377
1378            prev_nll, prev_c, final_nll, n_iter, converged, coef_delta = (
1379                float("inf"),
1380                flat_coefs(),
1381                float("nan"),
1382                0,
1383                False,
1384                float("inf"),
1385            )
1386            for _ in range(max(1, max_iter // chunk)):
1387                final_nll = float(opt.step(closure))
1388                n_iter += chunk
1389                cur_c = flat_coefs()
1390                coef_delta = float(np.abs(cur_c - prev_c).max())
1391                prev_c = cur_c
1392                if abs(prev_nll - final_nll) < tol * (1.0 + abs(final_nll)):
1393                    converged = True
1394                    break
1395                prev_nll = final_nll
1396            grad_norm = float(
1397                torch.cat(
1398                    [
1399                        p.grad.reshape(-1)
1400                        for p in self.parameters()
1401                        if p.grad is not None
1402                    ]
1403                ).norm()
1404            )
1405            coefs = self.ls_coefficients()  # read while still float64
1406        finally:
1407            self.float()  # restore canonical float32 (lossy ~1e-7, harmless)
1408        self.eval()
1409
1410        report = {
1411            "converged": converged,
1412            "n_iter": n_iter,
1413            "final_nll": final_nll,
1414            "grad_norm": grad_norm,
1415            "coef_delta": coef_delta,
1416            "seconds": time.perf_counter() - t0,
1417            "coefficients": coefs,
1418        }
1419        if verbose:
1420            logger.info(
1421                "fit_classical: %d L-BFGS iters, NLL %.6f, %.2fs%s",
1422                n_iter,
1423                final_nll,
1424                report["seconds"],
1425                "" if converged else f"  (NLL still moving at {max_iter} iters)",
1426            )
1427        return report

1430    @torch.no_grad()
1431    def sample(
1432        self,
1433        n: int | None = None,
1434        *,
1435        do: dict[str, float] | None = None,
1436        u: pd.DataFrame | None = None,
1437        seed: int | None = None,
1438    ) -> pd.DataFrame:
1439        """Sample from the flow, with optional interventions.
1440
1441        Parameters
1442        ----------
1443        n : int | None, optional
1444            Number of samples. Ignored if ``u`` is given.
1445        do : dict[str, float] | None, optional
1446            Interventions, as ``{node: value}``. An intervened node is
1447            clamped and its parent dependence removed (graph mutilation).
1448        u : pd.DataFrame | None, optional
1449            Latent variables, as returned by :meth:`abduct`. If given,
1450            they are pushed through the flow. Together with ``do`` this
1451            yields counterfactuals: Pearl's abduction, action, prediction.
1452        seed : int | None, optional
1453            If given, seeds the latent draw. Ignored if ``u`` is given.
1454
1455        Returns
1456        -------
1457        pd.DataFrame
1458            The samples, one column per node.
1459
1460        Raises
1461        ------
1462        ValueError
1463            If both ``n`` and ``u`` are omitted.
1464        """
1465        do = do or {}
1466        gen = (
1467            None
1468            if seed is None
1469            else torch.Generator(device=self.device).manual_seed(seed)
1470        )
1471
1472        np_dtype = self._np_dtype
1473        if u is not None:
1474            n = len(u)
1475            u_vals = {
1476                name: torch.as_tensor(
1477                    u[name].to_numpy(dtype=np_dtype, copy=True), device=self.device
1478                )
1479                for name in self.order
1480            }
1481        elif n is not None:
1482            u_vals = {
1483                name: StandardLogistic.sample((n,), device=self.device, generator=gen)
1484                for name in self.order
1485            }
1486        else:
1487            raise ValueError("Provide either n or u.")
1488
1489        values: dict[str, Tensor] = {}
1490        for name in self.order:
1491            if name in do:
1492                values[name] = torch.full(
1493                    (n,), float(do[name]), dtype=self._dtype, device=self.device
1494                )
1495                continue
1496            node = self.nodes[name]
1497            feats = self._features({p: values[p] for p in node.parents})
1498            # centered VC: e_hat(pa_on) is re-derived from the already-sampled
1499            # ancestor values — under do the regressor is t_do - e_hat(x), never
1500            # a cached training value
1501            theta, shift = node.theta_shift(
1502                feats, n, vc_ehat=self._vc_ehat_live(node, values, n)
1503            )
1504            z = u_vals[name]
1505            if node.kind == "continuous":
1506                values[name] = node.ut.inverse(theta, z - shift)
1507            else:
1508                values[name] = ordinal_sample(theta, shift, z)
1509        return pd.DataFrame({k: v.cpu().numpy() for k, v in values.items()})

1511    @torch.no_grad()
1512    def abduct(self, df: pd.DataFrame, seed: int | None = None) -> pd.DataFrame:
1513        """Recover the latent variables ``u`` from observations (Pearl step 1).
1514
1515        A continuous node inverts exactly: ``u = h(x) + shift``. For an
1516        ordinal node the latent is only interval-identified, so it is
1517        sampled from the standard logistic truncated to the observed
1518        level's interval.
1519
1520        Parameters
1521        ----------
1522        df : pd.DataFrame
1523            Observations, one column per node.
1524        seed : int | None, optional
1525            If given, seeds the truncated draw for the ordinal nodes.
1526
1527        Returns
1528        -------
1529        pd.DataFrame
1530            The latents, one column per node, aligned with the rows of
1531            ``df``.
1532        """
1533        gen = (
1534            None
1535            if seed is None
1536            else torch.Generator(device=self.device).manual_seed(seed)
1537        )
1538        values = self._tensorize(df)
1539        feats = self._features(values)
1540        n = len(df)
1541        u = {}
1542        for name in self.order:
1543            node = self.nodes[name]
1544            theta, shift = node.theta_shift(
1545                feats, n, vc_ehat=self._vc_ehat_live(node, values, n)
1546            )
1547            x = values[name]
1548            if node.kind == "continuous":
1549                z0, _ = node.ut.forward(theta, x)
1550                u[name] = z0 + shift
1551            else:
1552                u[name] = ordinal_abduct(theta, shift, x, generator=gen)
1553        return pd.DataFrame({k: v.cpu().numpy() for k, v in u.items()})

Build a varying-coefficient shift term beta(modifiers) * x_t.

VC is the exported alias of this function, the notation of the docs and the paper.

This is the treatment-effect term of issue #28: VC("X2", "X3", t="T") is (beta0 + b_theta(x2, x3)) * x_t.

beta(x) = beta0 + b_theta(x), with b_theta a small MLP whose weights carry the L2 penalty. The fitting objective is the penalized NLL sum_i nll_i + penalty * ||b_theta weights||^2 on the total-likelihood scale. That is a fixed Gaussian prior whose shrinkage vanishes as n grows. beta0 is not penalized.

The output of b_theta is zero-initialized and, after the fit, mean-centered over the training data. beta0 is therefore the interpretable main effect on the log-odds scale — the classical Colr/LS reading when beta is constant. penalty -> inf, or exactly zero modifiers, reduces the term to LS(t), so VC-vs-LS is a nested question. Read the fitted effect out with CausalFlowDAG.varying_coef().

Unlike other effects, VC modifiers can also appear in the node's prognostic terms (CS/LS/I). Only t owns its edge.

Parameters
  • *modifiers (str): The effect modifiers — the covariates that enter b_theta. Empty means a constant effect.
  • t (str): The treatment (required keyword). Must be a continuous node or a binary (2-level) ordinal node. The term is linear in x_t.
  • penalty (float, optional): L2 weight on the b_theta weights, by default 1.0. Must be >= 0.
  • center (bool, optional): Propensity centering (issue #30), by default False. True uses the propensity-centered regressor beta(x) * (x_t - e_hat(pa_t)) — the Robinson/R-learner orthogonalization inside the likelihood. Requires a binary ordinal t.
  • center_folds (int, optional): Fold count for the out-of-fold refits under center=True, by default 5. Must be >= 2.
  • units (list[int] | tuple[int, ...] | None, optional): Hidden layers of b_theta, by default [16].
Returns
  • Term: The varying-coefficient term.
Raises
  • ValueError: If t is also a modifier, if penalty is negative, or if center_folds is below 2.
Notes

With center=True, training uses out-of-fold e_hat: center_folds-fold refits of the t node only, the DML requirement — in-sample centering can be worse than none. The values are frozen as data, so no gradient reaches the t node from this node's loss. Inference (log_prob/sample/abduct/pmf) recomputes e_hat from the flow's own fitted t node — the full-data fit, the standard DML train/predict split — and always re-derives x_t - e_hat under do, never from a cache. With centering, beta0 is the effect at the treatment margin (the observed propensities). The LS-nesting reading applies to the uncentered term only.
