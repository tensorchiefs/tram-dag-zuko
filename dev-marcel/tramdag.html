tramdag — Interpretable Neural Causal Models (TRAM-DAGs) in PyTorch.

tramdag — Interpretable Neural Causal Models (TRAM-DAGs) in PyTorch

⚠️ Status: beta (0.x), under active development. The API may change between releases until 1.0, so pin a version for reproducibility. Note that this README documents the unreleased 0.4 API: the term constructors (SI/CI/VC), scores, varying_coef and intercept_contributions are not in 0.3.0 on PyPI. Until 0.4 ships, install from git to follow the docs below.

TRAM-DAGs model each variable of a structural causal model with a (transformation-model) flow: one triangular normalizing flow from iid standard-logistic latents to the observed variables. The triangular adjacency structure is exactly your causal DAG. Fit it once on observational data and answer all three rungs of Pearl's causal hierarchy — observational (L1), interventional (L2, the do-operator), and counterfactual (L3, Pearl abduction) — while keeping interpretable effects: every linear-shift coefficient is a log-odds ratio, exactly as in classical proportional-odds models.

Beate Sick & Oliver Dürr, Interpretable Neural Causal Models with TRAM-DAGs, CLeaR 2025 (arXiv:2503.16206). This repo is the reference implementation (PyTorch, built on zuko); all of the paper's experiments are replicated here with pinned tests.

5-minute showcase: the Colab badge above fits the paper's bimodal benchmark live and walks L1 → L2 → L3, every answer checked against analytic ground truth. Further notebooks are available at notebooks/ like the didactic walkthrough of the model: notebooks/intro_tram_dag.py.

30 seconds of API

from tramdag import CausalFlowDAG, ContinuousNode, OrdinalNode, I, LS, CS

spec = {  # the spec IS the labelled DAG
    "X1": ContinuousNode(),
    "X2": ContinuousNode(I("X1")),
    "T": OrdinalNode(2, LS("X1") + CS("X2")),  # 2 levels, column coded 0..1
    "Y": OrdinalNode(4, I("X1") + CS("X2") + LS("T")),
}
# train_df / val_df: DataFrames with one column per node
flow = CausalFlowDAG(spec)  # validates acyclicity, builds the flow

# fit() is one minibatch Adam loop; validation, schedules and early stopping
# attach through optimizer= and the callback hooks — the common recipes ship
# in tramdag.callbacks (docs/fitting.md)
from tramdag.callbacks import Logger, RestoreBest

best = RestoreBest(val_df)  # keep the best-validation weights
flow.fit(
    train_df,
    epochs=4000,
    batch_size=512,
    after_epoch_callbacks=[Logger(val_df, every=100), best],
    after_fit_callbacks=[best.restore],
)

# all-`ls` model? fit it classically instead: deterministic float64 L-BFGS,
# exact MLE matching statsmodels/R (see docs/fitting.md)
flow.fit_classical(train_df)  # raises on cs/ci/vc specs

flow.log_prob(df)  # L1: joint log-likelihood per row
flow.sample(1000)  # L1: observational sampling
flow.sample(1000, do={"T": 1})  # L2: interventional (graph mutilation)
flow.pmf(df, node="Y", do={"T": 1})  # L2: analytic interventional PMF
flow.density(df, node="X2", grid=grid, do={"X1": 0.5})  # ... and density, continuous nodes

u = flow.abduct(df)  # L3 step 1: latents from observations
cf = flow.sample(do={"T": 1}, u=u)  # L3 steps 2+3: counterfactuals

flow.ls_coefficients()  # interpret: per-edge log-odds-ratios (LS terms)
# per-parent partial effects of an additive complex intercept (centered):
# flow.intercept_contributions(df, "Y") on a CI("A", "B", allow_interaction=False)

# heterogeneous treatment effects: a small, penalized effect head beta(x)*T
# (VC term) with a first-class read-out — see docs/varying-coefficients.md
# e.g. CS("X1", "X2") + VC("X1", t="T") ->
# flow.varying_coef(df, "Y")               # beta(x): deterministic, y-free

flow.scores(df, node="Y")  # per-observation scores dl_i/dtheta
flow.effect_modifier_scan(df, "Y", t="T")  # which VC modifiers? (CUSUM
# scan from a cheap all-ls fit) — docs/scores.md

The model in detail: spec → math → networks

Per node, the transformation is additive on the latent (log-odds) scale — one intercept term I plus any number of shifts (notation: docs/notation.md):

u = h_ϑ(x) + Σ β·x_pa + Σ g(x_pa) + (β₀ + b_Θ(x_mod))·x_t

term math what gets built interpretability
I() / bare I / omitted h_ϑ(x) — constant ϑ SimpleIntercept: one free parameter vector, no network the baseline transform
I("A") h_ϑ(a)(x) — ϑ bends with the parent ComplexIntercept: MLP [8, 8] → n_params the parent reshapes the whole distribution; no single coefficient
I("A","B") (default allow_interaction=True) h_ϑ(a,b)(x) one joint MLP over both parents — they interact in ϑ maximal flexibility
I("A","B", allow_interaction=False) h_ϑ(a)+ϑ(b)(x) one MLP per parent, parameter vectors summed in coefficient space per-parent partial effects via flow.intercept_contributions
LS("A") β·a Linear(width, 1), no bias — one parameter per feature column (one for a continuous parent, levels for a one-hot ordinal) exp(β) is an odds ratio
CS("A") g(a), additive ComplexShift: MLP [64, 128, 64] → 1 plot g
CS("A","B") g(a,b) — joint one MLP over the concatenated features interaction in the shift
CS("A") + CS("B") g₁(a) + g₂(b) two MLPs, scalars added GAM-style, each effect plottable
VC("A","B", t="T") (β₀ + b_Θ(a,b))·x_t scalar β₀ + zero-initialised penalized MLP [16] → 1; the treatment value multiplies, it never enters the net β₀ ≈ constant effect, flow.varying_coef reads β(x)

A node takes at most one I term with parents — a term list is therefore always purely additive on the latent scale, and interactions exist only inside a term. Lists and + sums are interchangeable: [LS("A"), CS("B")] ≡ LS("A") + CS("B").

Two knobs on the terms:

  • transform= on I picks the basis of h_ϑ for a continuous node — "bernstein" (default, 20 coefficients, tails extrapolate with the boundary slope), "spline" (monotone RQ spline, 23 params at bins=8, fixed tail slope) or "affine" (2 params: the latent is exactly logistic). Ordinal nodes have no basis: their intercept is the cutpoint vector, P(x ≤ k) = σ(ϑ_k − shift).
  • units= on I/CS/VC sizes the term's network, e.g. units=[16] for one hidden layer of 16 neurons. The defaults match the PyTorch reference this package grew out of (buehlpa/TramDag, tram_models.py), not the TRAM-DAG paper's own R nets — so a replication sets units= and activation= explicitly, as the configs in experiments/paper/ do.

Feature widths: a continuous parent enters raw (1 column), an ordinal parent one-hot (levels columns). Abduction is exact for continuous nodes and truncated-logistic for ordinal ones, so flow.sample(u=flow.abduct(df)) reproduces df exactly / level-exactly.

There are two ways to fit the model: a stochastic deep learning optimizer (fit) and a 2nd order optimization like in the classical statistical models (fit_classical). The latter is more efficient for all-ls models (each node-conditional is then a classical transformation model). For more details, see the docs/fitting.md file.

Validation

Two layers, deliberately separate.

The framework's own test suite (tests/) measures the library against three inline data-generating processes it carries itself, so it needs no research code to run. Its strongest claim is an equality, not a similarity: an all-ls outcome node is an ordered-logit model, so the flow's MLE must match statsmodels OrderedModel on the same design matrix — it does, and the varying-coefficient acceptance bars (effect recovery, propensity centering) are pinned the same way. What the tests guarantee, and how each ground truth is obtained, is documented in tests/README.md.

The paper replications (experiments/) are separate: one self-contained script per dataset, with its hyperparameters in a sibling YAML file and its expected results committed under each area's ground_truth/. A dedicated workflow runs them and compares.

triangle_mixed.py (linear-ls, exp-cs) §6.2 mixed data L1/L2 + the C.4 odds-ratio check (OR ≈ 7.4)

Build a varying-coefficient shift term beta(modifiers) * x_t.

VC is the exported alias of this function, the notation of the docs and the paper.

This is the treatment-effect term of issue #28: VC("X2", "X3", t="T") is (beta0 + b_theta(x2, x3)) * x_t.

beta(x) = beta0 + b_theta(x), with b_theta a small MLP whose weights carry the L2 penalty. The fitting objective is the penalized NLL sum_i nll_i + penalty * ||b_theta weights||^2 on the total-likelihood scale. That is a fixed Gaussian prior whose shrinkage vanishes as n grows. beta0 is not penalized.

The output of b_theta is zero-initialized and, after the fit, mean-centered over the training data. beta0 is therefore the interpretable main effect on the log-odds scale — the classical Colr/LS reading when beta is constant. penalty -> inf, or exactly zero modifiers, reduces the term to LS(t), so VC-vs-LS is a nested question. Read the fitted effect out with CausalFlowDAG.varying_coef().

Unlike other effects, VC modifiers can also appear in the node's prognostic terms (CS/LS/I). Only t owns its edge.

Parameters
  • *modifiers (str): The effect modifiers — the covariates that enter b_theta. Empty means a constant effect.
  • t (str): The treatment (required keyword). Must be a continuous node or a binary (2-level) ordinal node. The term is linear in x_t.
  • penalty (float, optional): L2 weight on the b_theta weights, by default 1.0. Must be >= 0. 1.0 is the value at which tests/test_vc_term.py recovers the known beta(x) of the vc_hetero DGP at corr ~ 0.99. The penalty is on the total-NLL scale, so its effective strength moves with n: raise it for small n or many modifiers.
  • center (bool, optional): Propensity centering (issue #30), by default False, which is bit-identical to the uncentered term — so a plain VC stays what it was before centering existed, and every committed number keeps reproducing. docs/varying-coefficients.md measures a 5-10x bias reduction from turning it on, so turn it on for an effect estimate. True uses the propensity-centered regressor beta(x) * (x_t - e_hat(pa_t)) — the Robinson/R-learner orthogonalization inside the likelihood. Requires a binary ordinal t.
  • units (list[int] | tuple[int, ...] | None, optional): Hidden layers of b_theta, by default [16] — see tramdag.conditioners.VaryingCoef for why that size.
  • activation (str | None, optional): Activation of b_theta's hidden layers, by default the conditioners' relu.
Returns
  • Term: The varying-coefficient term.
Raises
  • ValueError: If t is also a modifier or if penalty is negative.
Notes

With center=True, training needs out-of-fold e_hat for every training row, passed as fit(vc_ehat=) — the DML cross-fitting requirement; in-sample centering can be worse than none. The values are frozen as data, so no gradient reaches the t node from this node's loss. Inference (log_prob/sample/abduct/pmf) recomputes e_hat from the flow's own fitted t node — the full-data fit, the standard DML train/predict split — and always re-derives x_t - e_hat under do, never from a cache.  810    def _vc_ehat_train(
 811        self, train_df: pd.DataFrame, vc_ehat: dict | None
 812    ) -> dict[str, dict[str, Tensor]] | None:
 813        """Turn the user's stage-1 propensities into the training-time tensors.
 814
 815        A centered ``VC`` term needs ``vc_ehat[node][t]``: ``P(t = 1 | pa_t)``
 816        for every training row, positionally aligned with ``train_df``,
 817        computed **out of fold** (the cross-fitting
 818        requirement of the DML design; in-sample values reintroduce the
 819        own-observation bias). How they are computed is the user's choice —
 820        a ``fit_classical`` on the treatment spec per fold, or any
 821        classifier. The training loss uses these frozen values; every query
 822        after the fit uses the live treatment node (:meth:`_vc_ehat_live`).
 823        """
 824        centered = {
 825            (name, g.on)
 826            for name in self.order
 827            for g in self.nodes[name]._vc_groups
 828            if g.center
 829        }
 830        given = {(node, on) for node, d in (vc_ehat or {}).items() for on in d}
 831        if centered != given:
 832            raise ValueError(
 833                "fit(vc_ehat=) must hold exactly the centered VC terms "
 834                f"{sorted(centered)} as {{node: {{t: P(t=1|pa_t) per row}}}}, "
 835                f"got {sorted(given)}. The values must be out of fold."
 836            )
 837        if not centered:
 838            return None
 839        n = len(train_df)
 840        out: dict[str, dict[str, Tensor]] = {}
 841        for node, on in centered:
 842            e = np.asarray(vc_ehat[node][on], dtype=self._np_dtype).reshape(-1)
 843            if len(e) != n:
 844                raise ValueError(
 845                    f"vc_ehat[{node!r}][{on!r}] has {len(e)} rows, not {n}"
 846                )
 847            if not ((e >= 0) & (e <= 1)).all():
 848                raise ValueError(
 849                    f"vc_ehat[{node!r}][{on!r}] must hold probabilities in [0, 1]"
 850                )
 851            out.setdefault(node, {})[on] = torch.as_tensor(e, device=self.device)
 852        return out

 872        keeps the **final** weights: an all-``ls`` model trained to
 873        convergence reproduces the classical maximum-likelihood estimate and
 874        matches ``statsmodels`` and R ``polr``. A second ``fit`` call
 875        continues the training. Everything else — validation monitoring,
 876        learning-rate schedules, early stopping, best-weight restoration,
 877        logging — is the caller's, through ``optimizer`` and the callback
 878        hooks; :mod:`tramdag.callbacks` ships the common recipes::
 879
 880            from tramdag.callbacks import Logger, RestoreBest
 881
 882            best = RestoreBest(val_df)
 883            flow.fit(
 884                train_df,
 885                epochs=4000,
 886                after_epoch_callbacks=[Logger(val_df, every=50), best],
 887                after_fit_callbacks=[best.restore],
 888            )
 889
 890        Parameters
 891        ----------
 892        train_df : pd.DataFrame
 893            Training data, one column per node.
 894        epochs : int
 895            Number of passes over the data. There is no default: a fixed
 896            budget over-spends on some workloads and under-spends on others
 897            (docs/training-speed.md).
 898        learning_rate : float, optional
 899            Adam step size of the default optimizer, by default 1e-2.
 900            Ignored when ``optimizer`` is given.
 901        batch_size : int, optional
 902            Rows per gradient step, by default 512. ``len(train_df)`` is one
 903            full-batch step per epoch.
 904        seed : int | None, optional
 905            Seeds torch's global RNG before the loop, for the minibatch
 906            shuffling. Weight initialization is seeded at construction
 907            (``CausalFlowDAG(spec, seed=...)``).
 908        optimizer : torch.optim.Optimizer | None, optional
 909            Any torch optimizer over ``flow.parameters()``; the default is
 910            ``Adam(lr=learning_rate)``. Build it yourself to attach a
 911            ``torch.optim.lr_scheduler`` or to continue with its state.
 912        before_fit_callbacks : callable | list[callable] | None, optional
 913            Each called as ``cb(flow, optimizer)`` once, after calibration
 914            and before the first epoch.
 915        after_epoch_callbacks : callable | list[callable] | None, optional
 916            Each called as ``cb(flow, epoch, optimizer)`` after every epoch
 917            (``epoch`` counts from 1), once the epoch's train NLLs are in
 918            ``flow.history["train"]``. All of them run each epoch; the fit
 919            stops after an epoch in which any returned ``True``
 920            (``len(flow.history["train"])`` says how many epochs ran). Use them
 921            for validation (``flow.nll(val_df)``), schedules, snapshots and
 922            coefficient trajectories — :mod:`tramdag.callbacks` ships
 923            ``Logger``, ``RestoreBest`` and ``PerNodePlateau``.
 924        after_fit_callbacks : callable | list[callable] | None, optional
 925            Each called as ``cb(flow, optimizer)`` once, after the loop and
 926            **before** the VC re-centering — so a callback that swaps the
 927            weights (``RestoreBest.restore``) hands them to the re-centering.
 928        vc_ehat : dict | None, optional
 929            Out-of-fold propensities ``{node: {t: array}}`` for every centered
 930            ``VC`` term, one value per training row; required when the spec
 931            has one (see docs/varying-coefficients.md).
 932
 933        Returns
 934        -------
 935        CausalFlowDAG
 936            ``self``, fitted, in eval mode.
 937
 938        Raises
 939        ------
 940        ValueError
 941            If ``epochs`` or ``batch_size`` is below 1, or ``vc_ehat`` does
 942            not match the centered VC terms of the spec.
 943        TypeError
 944            If a callback does not accept its hook's arguments — checked
 945            before the first epoch, so a mis-registered callback cannot
 946            waste a run.
 947
 948        Notes
 949        -----
 950        For ``VC`` terms the objective is the **penalized** NLL on the
 951        total-likelihood scale: each term adds
 952        ``penalty * ||b_theta weights||^2`` to the summed NLL, that is
 953        ``penalty * ||w||^2 / n_train`` to the mean loss — a fixed Gaussian
 954        prior whose shrinkage vanishes as n grows. ``beta0`` is not
 955        penalized, and ``history["train"]`` holds pure likelihoods. After
 956        the loop each ``b_theta`` is re-centered to mean zero over the
 957        training rows; the constant moves into ``beta0``, the function is
 958        unchanged.
 959        """
 960        if epochs < 1:
 961            raise ValueError(f"epochs must be at least 1, got {epochs}")
 962        if batch_size < 1:
 963            raise ValueError(f"batch_size must be at least 1, got {batch_size}")
 964        before = _callback_list(before_fit_callbacks)
 965        after_epoch = _callback_list(after_epoch_callbacks)
 966        after_fit = _callback_list(after_fit_callbacks)
 967        _check_callbacks(before, ("flow", "optimizer"), "before_fit")
 968        _check_callbacks(after_epoch, ("flow", "epoch", "optimizer"), "after_epoch")
 969        _check_callbacks(after_fit, ("flow", "optimizer"), "after_fit")
 970        if seed is not None:
 971            torch.manual_seed(seed)
 972        ehat = self._vc_ehat_train(train_df, vc_ehat)  # validate before calibrating
 973        self.calibrate(train_df)
 974        vals = self._tensorize(train_df)
 975        opt = optimizer or torch.optim.Adam(self.parameters(), lr=learning_rate)
 976        penalized = [
 977            nd.shifts[g.on]
 978            for nd in self.nodes.values()
 979            for g in nd._vc_groups
 980            if g.mods and nd.shifts[g.on].penalty > 0
 981        ]
 982        for cb in before:
 983            cb(self, opt)
 984        for epoch in range(1, epochs + 1):
 985            self.train()
 986            self.history["train"].append(
 987                self._fit_epoch(vals, ehat, opt, batch_size, penalized)
 988            )
 989            self.eval()
 990            # every callback runs (a stop must not skip the logger)
 991            stops = [bool(cb(self, epoch, opt)) for cb in after_epoch]
 992            if any(stops):
 993                break
 994        for cb in after_fit:
 995            cb(self, opt)  # before the re-centering: restored weights re-center too
 996        self._recenter_vc(vals)
 997        self.eval()
 998        return self

1000    def _fit_epoch(
1001        self,
1002        vals: dict[str, Tensor],
1003        ehat: dict[str, dict[str, Tensor]] | None,
1004        opt: torch.optim.Optimizer,
1005        batch_size: int,
1006        penalized: list,
1007    ) -> dict[str, float]:
1008        """One shuffled pass over the rows; give the epoch-mean train NLL per node."""
1009        n = len(next(iter(vals.values())))
1010        acc = dict.fromkeys(self.order, 0.0)
1011        for idx in torch.randperm(n, device=self.device).split(batch_size):
1012            batch = {k: v[idx] for k, v in vals.items()}
1013            per_node = self.node_log_prob(batch, vc_ehat=_slice_ehat(ehat, idx))
1014            nlls = {k: -v.mean() for k, v in per_node.items()}
1015            loss = torch.stack(list(nlls.values())).sum()
1016            for m in penalized:  # the penalty joins the loss, not the history
1017                loss = loss + m.penalty * m.l2() / n
1018            opt.zero_grad()
1019            loss.backward()
1020            opt.step()
1021            w = len(idx) / n
1022            for k, v in nlls.items():
1023                acc[k] += float(v.detach()) * w
1024        return acc

1027    def _recenter_vc(self, values: dict[str, Tensor]) -> None:
1028        """Re-split every VC term so ``b_theta`` sums to zero over the train rows.
1029
1030        The removed constant moves into ``beta0``, so the modelled function does
1031        not change.
1032        """
1033        feats: dict[str, Tensor] | None = None
1034        for name in self.order:
1035            nd = self.nodes[name]
1036            for g in nd._vc_groups:
1037                if not g.mods:
1038                    continue
1039                if feats is None:
1040                    feats = self._features(values)
1041                nd.shifts[g.on].recenter(nd.net_input(feats, g.mods))

1043    @torch.no_grad()
1044    def varying_coef(
1045        self, df: pd.DataFrame, node: str, *, t: str | None = None
1046    ) -> np.ndarray:
1047        """Evaluate the fitted effect function ``beta(x)`` of a ``VC`` term.
1048
1049        This is the first-class read-out of issue #28. The value comes in
1050        closed form from the fitted term, as ``beta0 + b_theta(modifiers)``.
1051        It is deterministic and needs no abduction. It is free of ``y``,
1052        because only the modifier columns of ``df`` are read. For a binary
1053        treatment it is identical to the abduction difference
1054        ``u(x, t=1, y) - u(x, t=0, y)``.
1055
1056        The value lives on the latent, log-odds scale of the node. A
1057        continuous node adds it. An ordinal node subtracts it from the
1058        cutpoints.
1059
1060        For a centered term (``center=...``) the form of the returned
1061        ``beta`` does not change. ``beta0`` then reads as the effect at the
1062        treatment margin, which is the observed propensities.
1063
1064        Parameters
1065        ----------
1066        node : str
1067            Name of the node that carries the VC term.
1068        df : pd.DataFrame
1069            Rows at which to evaluate ``beta``. Must contain every modifier
1070            column of the term.
1071        t : str | None, optional
1072            Treatment name of the VC term. Optional when the node has
1073            exactly one VC term.
1074
1075        Returns
1076        -------
1077        np.ndarray
1078            The ``beta`` values, shape ``(n,)``. Constant when the term has
1079            no modifiers.
1080
1081        Raises
1082        ------
1083        KeyError
1084            If ``node`` is unknown, if the node has no VC term on ``t``, or
1085            if a modifier column is missing from ``df``.
1086        ValueError
1087            If the node has no VC term, or if ``t`` is omitted while the
1088            node has several VC terms.
1089        """
1090        nd = self._node(node)
1091        vcs = {g.on: g.mods for g in nd._vc_groups}
1092        if not vcs:
1093            raise ValueError(f"node {node!r} has no VC term.")
1094        if t is None:
1095            if len(vcs) > 1:
1096                raise ValueError(
1097                    f"node {node!r} has several VC terms ({sorted(vcs)}). "
1098                    "Pass t=<treatment name>."
1099                )
1100            t = next(iter(vcs))
1101        if t not in vcs:
1102            raise KeyError(
1103                f"node {node!r} has no VC term on {t!r} (has {sorted(vcs)})."
1104            )
1105        mods = vcs[t]
1106        mod_feat = None
1107        if mods:
1108            feats = self._features(self._tensorize(df, mods))
1109            mod_feat = nd.net_input(feats, mods)
1110        return nd.shifts[t].beta(mod_feat, len(df)).cpu().numpy()

1120        """Give the per-node linear-shift weights.
1121
1122        For an all-``ls`` model these are the interpretable log-odds-ratio
1123        coefficients.
1124
1125        Only ``LS`` terms have a weight to give. A node's ``CS`` and ``VC``
1126        shifts are networks, so they are skipped — reading them needs

1128
1129        Returns
1130        -------

1138                parent: module.weight.detach().cpu().numpy().ravel().copy()
1139                for parent, module in self.nodes[name].shifts.items()
1140                if isinstance(module, LinearShift)
1141            }
1142            if linear:
1143                out[name] = linear

1169    @torch.no_grad()
1170    def intercept_contributions(self, df: pd.DataFrame, node: str) -> dict:
1171        """Decompose a complex intercept into mean-centered per-term parts.
1172
1173        The parts are contributions to the transform parameters of the node.
1174        Use them to plot additive partial effects.
1175
1176        An additive complex intercept,
1177        ``CI("x1", "x2", allow_interaction=False)``, builds one
1178        network per ``I`` term and **sums their outputs in unconstrained
1179        parameter space**: ``theta(pa) = net_1(x1) + net_2(x2)``. The sum is
1180        identified, so every L1/L2/L3 query is correct. Each term's output,
1181        however, is identified only up to a constant — a constant moves
1182        freely between the nets. The *raw* per-term outputs are therefore
1183        not directly comparable.
1184
1185        This method resolves the ambiguity with the usual additive-model
1186        (GAM) convention: a **sum-to-zero (mean-centering) constraint over
1187        the rows of** ``df``. Each term's contribution is centered to mean
1188        zero per parameter. The removed constants collect into a single
1189        ``baseline``. The decomposition is exact:
1190
1191            ``theta(pa) = baseline + sum_terms contribution_term(pa)``
1192
1193        ``baseline`` plus the uncentered row sum of the contributions
1194        reproduces the model's transform parameters. This is **post-hoc
1195        only**: it reads the fitted weights and changes nothing about the
1196        model or any frozen number (issue #20, Option A). Shift terms
1197        (``LS``/``CS``) are a separate, already-interpretable slot — see
1198        :meth:`ls_coefficients`.
1199
1200        Parameters
1201        ----------
1202        node : str
1203            Name of a node with at least one complex-intercept (``I``) term
1204            that has parents.
1205        df : pd.DataFrame
1206            Rows over which to center and at which to evaluate the
1207            contributions. Must contain every intercept-parent column.
1208
1209        Returns
1210        -------
1211        dict
1212            Three keys. ``"baseline"`` is the absorbed constant, a ``(P,)``
1213            array — the sum of the per-term means. ``P`` is the node's
1214            transform-parameter count: ``ut.n_params`` for a continuous
1215            node, ``levels - 1`` cutpoint parameters for an ordinal node.
1216            ``"contributions"`` is ``{term_label: (n, P) array}`` — each
1217            term's mean-centered contribution at each row, columns summing
1218            to about zero over the rows. ``term_label`` is the term's
1219            parents joined by ``"+"``. ``"parents"`` is
1220            ``{term_label: tuple(parent_names)}``.
1221
1222        Raises
1223        ------
1224        KeyError
1225            If ``node`` is unknown, or if an intercept-parent column is
1226            missing from ``df``.
1227        ValueError
1228            If the node has no complex-intercept term with parents.
1229
1230        Notes
1231        -----
1232        The contributions live in the transform's **unconstrained**
1233        parameter space, where the model sums the additive terms before the
1234        monotonicity constraint. They are exact partial effects on those
1235        parameters, but not, in general, an additive shift of the curve
1236        itself.
1237        """
1238        nd = self._node(node)
1239        groups = nd._intercept_groups
1240        if not groups:
1241            raise ValueError(
1242                f"node {node!r} has no complex-intercept (I) terms with parents. "
1243                "Its intercept is unconditional, so there is nothing to decompose."
1244            )
1245        missing = [p for p in nd.ci_parents if p not in df.columns]
1246        if missing:
1247            raise KeyError(f"df is missing intercept-parent column(s): {missing}")
1248
1249        feats = self._features(self._tensorize(df, nd.ci_parents))
1250        # one net per group: the additive case stores them in intercept_nets;
1251        # a single (possibly joint) I-term is the lone `intercept` network.
1252        nets = (
1253            list(nd.intercept_nets) if nd.intercept_nets is not None else [nd.intercept]
1254        )
1255
1256        contributions: dict[str, np.ndarray] = {}
1257        parents: dict[str, tuple] = {}
1258        baseline = None
1259        for net, grp in zip(nets, groups, strict=True):
1260            raw = net(nd.net_input(feats, grp))  # (n, P)
1261            mean = raw.mean(dim=0, keepdim=True)  # (1, P)
1262            label = "+".join(grp)
1263            contributions[label] = (raw - mean).cpu().numpy()
1264            parents[label] = grp
1265            baseline = mean if baseline is None else baseline + mean
1266        return {
1267            "baseline": baseline.cpu().numpy().ravel(),
1268            "contributions": contributions,
1269            "parents": parents,
1270        }

1272    @torch.no_grad()
1273    def design_matrix(
1274        self, df: pd.DataFrame, node: str, *, drop_first: bool = False
1275    ) -> pd.DataFrame:
1276        """Encode a node's parents the way the flow feeds them to its shifts.
1277
1278        A continuous parent stays raw in one column named after it. An
1279        ordinal parent becomes one column per level, named
1280        ``"{parent}[{k}]"`` — the same one-hot the flow builds internally.
1281
1282        Use ``drop_first=True`` to get the design a classical reference
1283        expects (``statsmodels`` ``OrderedModel``, R ``polr``): with
1284        cutpoints the full one-hot is unidentified, so each ordinal parent's
1285        level-0 column drops out and its remaining coefficients read as
1286        differences against level 0 — exactly what ``w[k] - w[0]`` gives on
1287        the flow side.
1288
1289        Parameters
1290        ----------
1291        df : pd.DataFrame
1292            Rows to encode. Must contain every parent column of ``node``.
1293        node : str
1294            Name of the node whose parents are encoded.
1295        drop_first : bool, optional
1296            Drop each ordinal parent's level-0 column, by default ``False``.
1297
1298        Returns
1299        -------
1300        pd.DataFrame
1301            One column per encoded feature, indexed like ``df``.
1302        """
1303        nd = self._node(node)
1304        feats = self._features(self._tensorize(df, nd.parents))
1305        cols: dict[str, np.ndarray] = {}
1306        for p in nd.parents:
1307            arr = feats[p].cpu().numpy()
1308            if arr.shape[1] == 1:  # continuous parent: raw
1309                cols[p] = arr[:, 0]
1310            else:
1311                for k in range(1 if drop_first else 0, arr.shape[1]):
1312                    cols[f"{p}[{k}]"] = arr[:, k]
1313        return pd.DataFrame(cols, index=df.index)

1315    def fit_classical(
1316        self,
1317        train_df: pd.DataFrame,
1318        *,
1319        max_iter: int = 400,
1320        tol: float = 1e-9,
1321        history_size: int = 50,
1322    ) -> dict:
1323        """Fit an all-``ls`` model the classical way.
1324
1325        The fit uses full batches, float64, and L-BFGS with a strong-Wolfe
1326        line search. There are no minibatches, no schedule and no early
1327        stopping, so the fit is deterministic and bit-reproducible. It lands
1328        on the exact maximum-likelihood estimate and matches classical
1329        software, that is ``statsmodels`` ``OrderedModel`` and R ``polr`` or
1330        ``Colr``. It is much faster than minibatch Adam.
1331
1332        This method is valid only when every edge is ``ls``, because each
1333        node-conditional is then a classical transformation model. Any other
1334        model raises. For a ``cs`` or ``ci`` model use :meth:`fit`, where
1335        the minibatch noise also regularizes the MLPs.
1336
1337        Parameters
1338        ----------
1339        train_df : pd.DataFrame
1340            Training data, one column per node.
1341        max_iter : int, optional
1342            Upper limit on L-BFGS iterations, by default 400.
1343        tol : float, optional
1344            torch's ``tolerance_change``: the NLL (or parameter) change below
1345            which L-BFGS stops, by default 1e-9. Measured on the classical
1346            anchor: 1e-6 stops on a plateau step and leaves a rare one-hot
1347            level 0.24 off statsmodels; 1e-9 lands within 0.03, the same as
1348            running to the iteration cap.
1349        history_size : int, optional
1350            L-BFGS memory, by default 50.
1351
1352        Returns
1353        -------
1354        dict
1355            A convergence report: ``converged``, ``n_iter``, ``final_nll``,
1356            ``grad_norm``, ``seconds``, and the fitted ``coefficients``
1357            from :meth:`ls_coefficients`.
1358
1359        Raises
1360        ------
1361        ValueError
1362            If the spec has ``cs``, ``ci`` or ``vc`` terms.
1363
1364        Notes
1365        -----
1366        float64 is a transient compute mode. The model is upcast for the
1367        fit, and ``self.double()`` converts the parameters and the range
1368        buffers of the transforms in one call. Afterwards the model returns
1369        to float32, so the stored model and ``save``/``load`` stay float32.
1370        Double precision is what lets the line search resolve the optimum
1371        cleanly.
1372
1373        Convergence is torch's own: L-BFGS stops when the NLL or the
1374        parameters move by less than ``tol`` (``tolerance_grad`` is set to
1375        0, so the gradient never ends the run). ``|grad|`` and individual
1376        coefficients do *not* settle to machine precision. A continuous
1377        node's Bernstein intercept, and weakly-identified directions such
1378        as rare one-hot levels or a flat treatment-effect ridge, keep
1379        drifting along near-zero-curvature valleys long after the
1380        likelihood and the well-identified coefficients reach the MLE.
1381        Correctness is therefore verified by comparison to classical
1382        software (see ``experiments/misc/validate_ls.py``), not by this flag.
1383        """
1384        if not self._is_classical():
1385            raise ValueError(
1386                "fit_classical requires an all-`ls` spec, that is every edge "
1387                "term 'ls'. This spec has cs, ci or vc terms. Use fit() for "
1388                "flexible models."
1389            )
1390        self.calibrate(train_df, marginal_init=False)  # L-BFGS needs no warm start
1391
1392        self.double()  # parameters + buffers (xmin/xmax) -> float64, one call
1393        t0 = time.perf_counter()
1394        try:
1395            vals = self._tensorize(train_df)
1396            self.train()
1397            opt = torch.optim.LBFGS(
1398                self.parameters(),
1399                lr=1.0,
1400                max_iter=max_iter,
1401                history_size=history_size,
1402                tolerance_grad=0.0,  # |grad| never settles on the flat ridges
1403                tolerance_change=tol,
1404                line_search_fn="strong_wolfe",
1405            )
1406
1407            def closure():
1408                opt.zero_grad()
1409                nll = torch.stack(
1410                    [-lp.mean() for lp in self.node_log_prob(vals).values()]
1411                ).sum()
1412                nll.backward()
1413                return nll
1414
1415            opt.step(closure)
1416            n_iter = next(iter(opt.state.values()))["n_iter"]
1417            converged = n_iter < max_iter  # torch stopped on a tolerance
1418            with torch.no_grad():
1419                final_nll = float(
1420                    torch.stack(
1421                        [-lp.mean() for lp in self.node_log_prob(vals).values()]
1422                    ).sum()
1423                )
1424            grad_norm = float(
1425                torch.nn.utils.get_total_norm(
1426                    [p.grad for p in self.parameters() if p.grad is not None]
1427                )
1428            )

585    weights carry the L2 ``penalty``. The fitting objective is the
586    penalized NLL ``sum_i nll_i + penalty * ||b_theta weights||^2`` on the
587    total-likelihood scale. That is a fixed Gaussian prior whose shrinkage
588    vanishes as n grows. ``beta0`` is not penalized.
589
590    The output of ``b_theta`` is zero-initialized and, after the fit,
591    mean-centered over the training data. ``beta0`` is therefore the
592    interpretable main effect on the log-odds scale — the classical
593    ``Colr``/``LS`` reading when ``beta`` is constant. ``penalty -> inf``,
594    or exactly zero modifiers, reduces the term to ``LS(t)``, so VC-vs-LS
595    is a nested question. Read the fitted effect out with
596    :meth:`CausalFlowDAG.varying_coef`.

620        reduction from turning it on, so turn it on for an effect estimate.

Build a varying-coefficient shift term beta(modifiers) * x_t.

VC is the exported alias of this function, the notation of the docs and the paper.

This is the treatment-effect term of issue #28: VC("X2", "X3", t="T") is (beta0 + b_theta(x2, x3)) * x_t.

beta(x) = beta0 + b_theta(x), with b_theta a small MLP whose weights carry the L2 penalty. The fitting objective is the penalized NLL sum_i nll_i + penalty * ||b_theta weights||^2 on the total-likelihood scale. That is a fixed Gaussian prior whose shrinkage vanishes as n grows. beta0 is not penalized.

The output of b_theta is zero-initialized and, after the fit, mean-centered over the training data. beta0 is therefore the interpretable main effect on the log-odds scale — the classical Colr/LS reading when beta is constant. penalty -> inf, or exactly zero modifiers, reduces the term to LS(t), so VC-vs-LS is a nested question. Read the fitted effect out with CausalFlowDAG.varying_coef().

Unlike other effects, VC modifiers can also appear in the node's prognostic terms (CS/LS/I). Only t owns its edge.

Parameters
  • *modifiers (str): The effect modifiers — the covariates that enter b_theta. Empty means a constant effect.
  • t (str): The treatment (required keyword). Must be a continuous node or a binary (2-level) ordinal node. The term is linear in x_t.
  • penalty (float, optional): L2 weight on the b_theta weights, by default 1.0. Must be >= 0. 1.0 is the value at which tests/test_vc_term.py recovers the known beta(x) of the vc_hetero DGP at corr ~ 0.99. The penalty is on the total-NLL scale, so its effective strength moves with n: raise it for small n or many modifiers.
  • center (bool, optional): Propensity centering (issue #30), by default False, which is bit-identical to the uncentered term — so a plain VC stays what it was before centering existed, and every committed number keeps reproducing. docs/varying-coefficients.md measures a 5-10x bias reduction from turning it on, so turn it on for an effect estimate. True uses the propensity-centered regressor beta(x) * (x_t - e_hat(pa_t)) — the Robinson/R-learner orthogonalization inside the likelihood. Requires a binary ordinal t.
  • units (list[int] | tuple[int, ...] | None, optional): Hidden layers of b_theta, by default [16] — see tramdag.conditioners.VaryingCoef for why that size.
  • activation (str | None, optional): Activation of b_theta's hidden layers, by default the conditioners' relu.
Returns
  • Term: The varying-coefficient term.
Raises
  • ValueError: If t is also a modifier or if penalty is negative.
Notes

With center=True, training needs out-of-fold e_hat for every training row, passed as fit(vc_ehat=) — the DML cross-fitting requirement; in-sample centering can be worse than none. The values are frozen as data, so no gradient reaches the t node from this node's loss. Inference (log_prob/sample/abduct/pmf) recomputes e_hat from the flow's own fitted t node — the full-data fit, the standard DML train/predict split — and always re-derives x_t - e_hat under do, never from a cache. With centering, beta0 is the effect at the treatment margin (the observed propensities). The LS-nesting reading applies to the uncentered term only.
