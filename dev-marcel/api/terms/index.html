    tramdag.terms¶

    tramdag.terms ¶

    The term modules: one class per effect, built from the effect's spec class.

    A spec term (:class:tramdag.spec.Term subclass — LS, CS, VC, Fn, I) is frozen data and carries the spec-level rules; the module here declares which term class it builds (data = CS) and owns the runtime behaviour: build, shift_value/theta_value, post_init, regularizer, finalize, score_columns and the side-input contract. :func:module_for finds the module of a term by that declaration, so subclassing is the whole registration.

    A custom effect is two classes: a :class:tramdag.spec.Term subclass for the options and checks, and a :class:ShiftTerm subclass with data = that term class, build and shift_value.

    TermDef ¶

    What every term module shares: the input transform and its calibration.

    data names the :class:tramdag.spec.Term subclass the module builds; :func:module_for dispatches on it.

    input_transform property ¶

    input_transform

    The term's frozen network-input transform, or None.

    Builds register one (_attach_input_transform) when the term declares input_transform= over continuous parents; a plain class attribute would shadow the registered submodule.

    __init_subclass__ ¶

    __init_subclass__(**kwargs)

    Stamp the module onto the term class it declares with data =.

    calibrate ¶

    calibrate(train_df)

    Freeze this term's data-dependent state: the input-transform stats.

    CausalFlowDAG.calibrate calls this once per term; a term without an input_transform has nothing to freeze. The intercept slot overrides it with two extra arguments (its node's own column and transform), which the flow passes only there.

    ShiftTerm ¶

    Bases: TermDef

    A shift term's behavior hooks, mixed into its conditioner.

    A built term instance carries key (its ModuleDict key, set by build) and parents (the term's written parents, set by the node); subclasses may add term-specific attributes (VaryingCoefficientTerm keeps mods/on_is_ord/center_col). build constructs the module exactly as the node used to, so state-dict paths and the seeded RNG stream stay bit-stable.

    build classmethod ¶

    build(term, spec)

    Construct the term module from its spec Term.

    shift_value ¶

    shift_value(node, feats)

    Give this term's contribution to the node's shift, shape (n,).

    feats holds the node's encoded parents plus this term's side columns (frozen from the data frame during training, injected live by the flow at query time).

    post_init ¶

    post_init()

    Re-apply construction-time invariants after a global weight init.

    regularizer ¶

    regularizer()

    Give the term's penalty on the total-likelihood scale, or None.

    finalize ¶

    finalize(node, feats)

    Run the term's post-fit step (after the after-fit callbacks).

    score_columns ¶

    score_columns(node, flow, feats, dlds)

    Give the per-observation score columns of this term's coefficients.

    Empty for a term with no interpretable coefficient (CS).

    side_columns ¶

    side_columns()

    Name the data-frame columns this term needs beyond the parents.

    Training reads them from train_df like any other column (so the validation split and the minibatch slicing come for free).

    check_column ¶

    check_column(node_name, col, values)

    Validate one side column's values at fit time.

    live_side ¶

    live_side(flow, values, n)

    Recompute the side columns from the fitted flow, at query time.

    extra_columns ¶

    extra_columns(flow)

    List the extra columns queries must tensorize for :meth:live_side.

    InterceptTerm ¶

    Bases: TermDef

    The intercept slot's behavior hooks, mixed into its module.

    A node has exactly one intercept term (normalization guarantees node.terms[0]); it produces the transform parameters theta. groups carries the parent groups — empty for a simple intercept, one tuple for a joint net, one per parent for an additive one — and ci_parents their flat order.

    build classmethod ¶

    build(term, spec, n_params)

    Construct the node's intercept module from its intercept Term.

    calibrate ¶

    calibrate(train_df, own=None, ut=None)

    Freeze the input stats and set the transform's domain, once.

    own is the node's own training column and ut its monotone transform (None for ordinal nodes — cutpoints have no domain): the train range_q/1 - range_q quantiles map onto the pre-scaled domain.

    theta_value ¶

    theta_value(node, feats, n)

    Give the transform parameters, shape (n, P).

    marginal_start ¶

    marginal_start(theta)

    Set the calibrated marginal start; only a free intercept has one.

    AdditiveInterceptTerm ¶

    Bases: InterceptTerm, Module

    allow_interaction=False: one net per parent, outputs summed.

    Each parent reshapes the transform independently, in unconstrained coefficient space.

    theta_value ¶

    theta_value(node, feats, n)

    Sum the per-parent nets in coefficient space.

    LinearShiftTerm ¶

    Bases: ShiftTerm, LinearShift

    LS — one raw-unit coefficient per (single) parent.

    build classmethod ¶

    build(term, spec)

    One weight per feature of the single parent; keyed by its name.

    shift_value ¶

    shift_value(node, feats)

    Give the raw parent column times the weight — no input transform.

    score_columns ¶

    score_columns(node, flow, feats, dlds)

    One column per weight: the parent (continuous) or its one-hot levels.

    d l_i / d beta = (d l_i / d s_i) * x_i — analytic and exact.

    ComplexShiftTerm ¶

    Bases: ShiftTerm, ComplexShift

    CS — a network shift over its parents.

    build classmethod ¶

    build(term, spec)

    One net over the concatenated parents; keyed 'a' or 'a+b'.

    shift_value ¶

    shift_value(node, feats)

    Give the net over this term's (possibly input-transformed) features.

    VaryingCoefficientTerm ¶

    Bases: ShiftTerm, VaryingCoef

    VC — beta(modifiers) * x_t; only the treatment owns an edge.

    build classmethod ¶

    build(term, spec)

    Build the effect head over the modifiers; keyed by the treatment name.

    regressor ¶

    regressor(feats)

    Give the (n, 1) column beta multiplies — the treatment, raw.

    The one-hot level-1 indicator for a binary ordinal treatment, the value itself for a continuous one; a centered term subtracts its propensity column (the Robinson regressor t - e_hat(x)). It is also the score of beta0, so :meth:score_columns reads it here.

    shift_value ¶

    shift_value(node, feats)

    beta(modifiers) * regressor, with the centered-term guard.

    post_init ¶

    post_init()

    Re-zero the head's output layer: beta(x) == beta0 at start.

    regularizer ¶

    regularizer()

    penalty * ||b_theta weights||^2 on the total-likelihood scale.

    None without a head to shrink (no modifiers, or penalty 0).

    finalize ¶

    finalize(node, feats)

    Re-split beta0/b_theta: the head sums to zero over train.

    score_columns ¶

    score_columns(node, flow, feats, dlds)

    One column, keyed by the treatment: the beta0 score.

    d s / d beta0 is the term's own :meth:regressor, so forward and score share one definition by construction.

    side_columns ¶

    side_columns()

    Name the propensity column a centered term reads from the frame.

    check_column ¶

    check_column(node_name, col, values)

    Propensities are probabilities.

    live_side ¶

    live_side(flow, values, n)

    Give the full-data propensity from the flow's own treatment node.

    Detached — no gradient reaches the treatment node from this node's loss — and derived from the current parent values, so do-mutilated sampling centers with the intervened t (the DML prediction convention; training uses the frozen out-of-fold column).

    extra_columns ¶

    extra_columns(flow)

    Give the treatment's parents (a treatment cannot be centered itself).

    FnShiftTerm ¶

    Bases: ShiftTerm, Module

    Fn — a user-supplied shift function over the parent features.

    A plain function contributes a fixed (non-trained) offset; an nn.Module registers as a submodule and trains with the flow. Built by :class:tramdag.spec.FnShift (Fn).

    build classmethod ¶

    build(term, spec)

    Wrap the callable; keyed like a CS ('a' or 'a+b').

    shift_value ¶

    shift_value(node, feats)

    Run fn on the term's features; accept (n,) or (n, 1).

    module_for ¶

    module_for(term)

    Give the module class that builds term.

    A :class:TermDef subclass that declares data = <Term subclass> stamps itself onto that class as module when it is defined (:meth:TermDef.__init_subclass__), so subclassing is the registration.

    Raises:

    Type Description
    ValueError

    If no module class declares the term's class.
