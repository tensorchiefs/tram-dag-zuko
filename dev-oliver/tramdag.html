tramdag — Interpretable Neural Causal Models (TRAM-DAGs) in PyTorch.

tramdag — Interpretable Neural Causal Models (TRAM-DAGs) in PyTorch

⚠️ Status: beta (0.x), under active development. The API may change between releases until 1.0, so pin a version for reproducibility. Note that this README documents the unreleased 0.4 API: the term constructors (SI/CI/VC), scores, varying_coef and intercept_contributions are not in 0.3.0 on PyPI. Until 0.4 ships, install from git to follow the docs below.

TRAM-DAGs model each variable of a structural causal model with a (transformation-model) flow: one triangular normalizing flow from iid standard-logistic latents to the observed variables. The triangular adjacency structure is exactly your causal DAG. Fit it once on observational data and answer all three rungs of Pearl's causal hierarchy — observational (L1), interventional (L2, the do-operator), and counterfactual (L3, Pearl abduction) — while keeping interpretable effects: every linear-shift coefficient is a log-odds ratio, exactly as in classical proportional-odds models.

Beate Sick & Oliver Dürr, Interpretable Neural Causal Models with TRAM-DAGs, CLeaR 2025 (arXiv:2503.16206). This repo is the reference implementation (PyTorch, built on zuko); all of the paper's experiments are replicated here with pinned tests.

5-minute showcase: the Colab badge above fits the paper's bimodal benchmark live (GPU-ready) and walks L1 → L2 → L3, every answer checked against analytic ground truth. Further notebooks are available at notebooks/ like the didactic walkthrough of the model: notebooks/intro_tram_dag.py.

30 seconds of API

from tramdag import CausalFlowDAG, ContinuousNode, OrdinalNode, I, LS, CS

spec = {  # the spec IS the labelled DAG
    "X1": ContinuousNode(),
    "X2": ContinuousNode(I("X1")),
    "T": OrdinalNode(2, LS("X1") + CS("X2")),
    "Y": OrdinalNode(4, I("X1") + CS("X2") + LS("T")),
}
flow = CausalFlowDAG(spec)  # validates acyclicity, builds the flow

# self-stopping training: per-node plateau lr decay + freezing of converged
# nodes (exact, since the per-node NLLs have independent gradients);
# see docs/training-speed.md for benchmarks and the classic two-phase recipe
flow.fit(
    train_df,
    val_df,
    epochs=4000,
    learning_rate=1e-2,
    batch_size=512,
    schedule="plateau",
    plateau_patience=30,
    freeze_patience=120,
)

# all-`ls` model? fit it classically instead: deterministic float64 L-BFGS,
# exact MLE matching statsmodels/R (see docs/fitting.md)
flow.fit_classical(train_df)  # raises on cs/ci specs

flow.log_prob(df)  # L1: joint log-likelihood per row
flow.sample(1000)  # L1: observational sampling
flow.sample(1000, do={"T": 1})  # L2: interventional (graph mutilation)
flow.pmf(df, node="Y", do={"T": 1})  # L2: analytic interventional PMF

u = flow.abduct(df)  # L3 step 1: latents from observations
cf = flow.sample(do={"T": 1}, u=u)  # L3 steps 2+3: counterfactuals

flow.ls_coefficients()  # interpret: per-edge log-odds-ratios (LS terms)
flow.intercept_contributions("Y", df)  # interpret: per-parent partial effects
# of an additive complex intercept (centered)

# heterogeneous treatment effects: a small, penalized effect head beta(x)*T
# (VC term) with a first-class read-out — see docs/varying-coefficients.md
# e.g. CS("X1", "X2") + VC("X1", t="T") ->
# flow.varying_coef("Y", df)               # beta(x): deterministic, y-free

flow.scores(df, node="Y")  # per-observation scores dl_i/dtheta
flow.effect_modifier_scan(df, "Y", t="T")  # which VC modifiers? (CUSUM
# scan from a cheap all-ls fit) — docs/scores.md

flow.save("flow.pt")
flow = CausalFlowDAG.load("flow.pt")

The model in detail: spec → math → networks

Per node, the transformation is additive on the latent (log-odds) scale — one intercept term I plus any number of shifts (notation: docs/notation.md):

u = h_ϑ(x) + Σ β·x_pa + Σ g(x_pa) + (β₀ + b_Θ(x_mod))·x_t

term math what gets built interpretability
I() / bare I / omitted h_ϑ(x) — constant ϑ SimpleIntercept: one free parameter vector, no network the baseline transform
I("A") h_ϑ(a)(x) — ϑ bends with the parent ComplexIntercept: MLP [8, 8] → n_params the parent reshapes the whole distribution; no single coefficient
I("A","B") (default allow_interaction=True) h_ϑ(a,b)(x) one joint MLP over both parents — they interact in ϑ maximal flexibility
I("A","B", allow_interaction=False) h_ϑ(a)+ϑ(b)(x) one MLP per parent, parameter vectors summed in coefficient space per-parent partial effects via flow.intercept_contributions
LS("A") β·a Linear(width, 1), no bias — one parameter exp(β) is an odds ratio
CS("A") g(a), additive ComplexShift: MLP [64, 128, 64] → 1 plot g
CS("A","B") g(a,b) — joint one MLP over the concatenated features interaction in the shift
CS("A") + CS("B") g₁(a) + g₂(b) two MLPs, scalars added GAM-style, each effect plottable
VC("A","B", t="T") (β₀ + b_Θ(a,b))·x_t scalar β₀ + zero-initialised penalized MLP [16] → 1; the treatment value multiplies, it never enters the net β₀ ≈ constant effect, flow.varying_coef reads β(x)

A node takes at most one I term with parents — a term list is therefore always purely additive on the latent scale, and interactions exist only inside a term. Lists and + sums are interchangeable: [LS("A"), CS("B")] ≡ LS("A") + CS("B").

Two knobs on the terms:

  • transform= on I picks the basis of h_ϑ for a continuous node — "bernstein" (default, 20 coefficients, tails extrapolate with the boundary slope), "spline" (monotone RQ spline, 23 params at bins=8, fixed tail slope) or "affine" (2 params: the latent is exactly logistic). Ordinal nodes have no basis: their intercept is the cutpoint vector, P(x ≤ k) = σ(ϑ_k − shift).
  • units= on I/CS/VC sizes the term's network, e.g. units=[16] for one hidden layer of 16 neurons. The defaults match the PyTorch reference this package grew out of (buehlpa/TramDag, tram_models.py), not the TRAM-DAG paper's own R nets — so a replication sets units= and activation= explicitly, as the configs in experiments/paper/ do.

Feature widths: a continuous parent enters raw (1 column), an ordinal parent one-hot (levels columns). Abduction is exact for continuous nodes and truncated-logistic for ordinal ones, so flow.sample(u=flow.abduct(df)) reproduces df exactly / level-exactly.

There are two ways to fit the model: a stochastic deep learning optimizer (fit) and a 2nd order optimization like in the classical statistical models (fit_classical). The latter is more efficient for all-ls models (each node-conditional is then a classical transformation model). For more details, see the docs/fitting.md file.

Validation

Two layers, deliberately separate.

The framework's own test suite (tests/) measures the library against three inline data-generating processes it carries itself, so it needs no research code to run. Its strongest claim is an equality, not a similarity: an all-ls outcome node is an ordered-logit model, so the flow's MLE must match statsmodels OrderedModel on the same design matrix — it does, and the varying-coefficient acceptance bars (effect recovery, propensity centering) are pinned the same way. What the tests guarantee, and how each ground truth is obtained, is documented in tests/README.md.

The paper replications (experiments/) are separate: one self-contained script per dataset, with its hyperparameters in a sibling YAML file and its expected results committed under each area's ground_truth/. A dedicated workflow runs them and compares.

experiment paper demonstrates
triangle.py (linear-ls, linear-cs, atan-cs, sin-cs) §6.1, C.3 LS coefficient recovery (β = 2, −0.2, +0.3), CS curve ≡ −f(x₂) for non-monotone f
triangle_mixed.py (linear-ls, exp-cs) §6.2 mixed data L1/L2 + the C.4 odds-ratio check (OR ≈ 7.4)
vaca.py §5.1–5.2 the bimodal L1 case a default CNF misses; L2 p(x₃ | do(x₂)) against analytic means

A figure-by-figure account of what is reproduced, and what is not (the competing CNF/NSF baselines), is in experiments/paper/PAPER_COVERAGE.md.

573    """Build a varying-coefficient shift term ``beta(modifiers) * x_t``.
574
575    ``VC`` is the exported alias of this function, the notation of the
576    docs and the paper.
577
578    This is the treatment-effect term of issue #28:
579    ``VC("X2", "X3", t="T")`` is ``(beta0 + b_theta(x2, x3)) * x_t``.
580
581    ``beta(x) = beta0 + b_theta(x)``, with ``b_theta`` a small MLP whose
582    weights carry the L2 ``penalty``. The fitting objective is the
583    penalized NLL ``sum_i nll_i + penalty * ||b_theta weights||^2`` on the
584    total-likelihood scale. That is a fixed Gaussian prior whose shrinkage
585    vanishes as n grows. ``beta0`` is not penalized.
586
587    The output of ``b_theta`` is zero-initialized and, after the fit,
588    mean-centered over the training data. ``beta0`` is therefore the
589    interpretable main effect on the log-odds scale — the classical
590    ``Colr``/``LS`` reading when ``beta`` is constant. ``penalty -> inf``,
591    or exactly zero modifiers, reduces the term to ``LS(t)``, so VC-vs-LS
592    is a nested question. Read the fitted effect out with
593    :meth:`CausalFlowDAG.varying_coef`.
594
595    Unlike other effects, VC *modifiers* can also appear in the node's
596    prognostic terms (``CS``/``LS``/``I``). Only ``t`` owns its edge.
597
598    Parameters
599    ----------
600    *modifiers : str
601        The effect modifiers — the covariates that enter ``b_theta``.
602        Empty means a constant effect.
603    t : str
604        The treatment (required keyword). Must be a continuous node or a
605        binary (2-level) ordinal node. The term is linear in ``x_t``.
606    penalty : float, optional

608        >= 0. 1.0 is the value at which ``tests/test_vc_term.py`` recovers
609        the known ``beta(x)`` of the ``vc_hetero`` DGP at corr ~ 0.99. The
610        penalty is on the total-NLL scale, so its effective strength moves
611        with ``n``: raise it for small ``n`` or many modifiers.
612    center : bool, optional

614        bit-identical to the uncentered term — so a plain ``VC`` stays what
615        it was before centering existed, and every committed number keeps
616        reproducing. ``docs/varying-coefficients.md`` measures a 5-10x bias
617        reduction from turning it on, so turn it on for an effect estimate.
618        ``True`` uses the **propensity-centered** regressor
619        ``beta(x) * (x_t - e_hat(pa_t))`` — the Robinson/R-learner
620        orthogonalization inside the likelihood. Requires a binary ordinal

630

633    Term

635

642    Notes
643    -----
644    With ``center=True``, training uses **out-of-fold** ``e_hat``:
645    ``center_folds``-fold refits of the ``t`` node only, the DML
646    requirement — in-sample centering can be *worse* than none. The values
647    are frozen as data, so no gradient reaches the ``t`` node from this
648    node's loss. Inference (``log_prob``/``sample``/``abduct``/``pmf``)
649    recomputes ``e_hat`` from the flow's own fitted ``t`` node — the
650    full-data fit, the standard DML train/predict split — and always

Build a varying-coefficient shift term beta(modifiers) * x_t.

VC is the exported alias of this function, the notation of the docs and the paper.

This is the treatment-effect term of issue #28: VC("X2", "X3", t="T") is (beta0 + b_theta(x2, x3)) * x_t.

beta(x) = beta0 + b_theta(x), with b_theta a small MLP whose weights carry the L2 penalty. The fitting objective is the penalized NLL sum_i nll_i + penalty * ||b_theta weights||^2 on the total-likelihood scale. That is a fixed Gaussian prior whose shrinkage vanishes as n grows. beta0 is not penalized.

The output of b_theta is zero-initialized and, after the fit, mean-centered over the training data. beta0 is therefore the interpretable main effect on the log-odds scale — the classical Colr/LS reading when beta is constant. penalty -> inf, or exactly zero modifiers, reduces the term to LS(t), so VC-vs-LS is a nested question. Read the fitted effect out with CausalFlowDAG.varying_coef().

Unlike other effects, VC modifiers can also appear in the node's prognostic terms (CS/LS/I). Only t owns its edge.

Parameters
  • *modifiers (str): The effect modifiers — the covariates that enter b_theta. Empty means a constant effect.
  • t (str): The treatment (required keyword). Must be a continuous node or a binary (2-level) ordinal node. The term is linear in x_t.
  • penalty (float, optional): L2 weight on the b_theta weights, by default 1.0. Must be >= 0. 1.0 is the value at which tests/test_vc_term.py recovers the known beta(x) of the vc_hetero DGP at corr ~ 0.99. The penalty is on the total-NLL scale, so its effective strength moves with n: raise it for small n or many modifiers.
  • center (bool, optional): Propensity centering (issue #30), by default False, which is bit-identical to the uncentered term — so a plain VC stays what it was before centering existed, and every committed number keeps reproducing. docs/varying-coefficients.md measures a 5-10x bias reduction from turning it on, so turn it on for an effect estimate. True uses the propensity-centered regressor beta(x) * (x_t - e_hat(pa_t)) — the Robinson/R-learner orthogonalization inside the likelihood. Requires a binary ordinal t.
  • center_folds (int, optional): Fold count for the out-of-fold refits under center=True, by default 5 — the standard cross-fitting count of double machine learning. Must be >= 2. Each fold costs one refit of the treatment node.
  • units (list[int] | tuple[int, ...] | None, optional): Hidden layers of b_theta, by default [16] — see tramdag.conditioners.VaryingCoef for why that size.
Returns
  • Term: The varying-coefficient term.
Raises
  • ValueError: If t is also a modifier, if penalty is negative, or if center_folds is below 2.
Notes

With center=True, training uses out-of-fold e_hat: center_folds-fold refits of the t node only, the DML requirement — in-sample centering can be worse than none. The values are frozen as data, so no gradient reaches the t node from this node's loss. Inference (log_prob/sample/abduct/pmf) recomputes e_hat from the flow's own fitted t node — the full-data fit, the standard DML train/predict split — and always re-derives x_t - e_hat under do, never from a cache. With centering, beta0 is the effect at the treatment margin (the observed propensities). The LS-nesting reading applies to the uncentered term only.

 534    def node_log_prob(
 535        self,
 536        values: dict[str, Tensor],
 537        nodes: list[str] | None = None,
 538        vc_ehat: dict[str, dict[str, Tensor]] | None = None,
 539    ) -> dict[str, Tensor]:
 540        """Compute the per-node log-likelihood contributions.
 541
 542        Parameters
 543        ----------
 544        values : dict[str, Tensor]
 545            Raw node values, keyed by node name, each shape ``(n,)``.
 546        nodes : list[str] | None, optional
 547            Restrict the computation to these nodes. ``fit`` uses this to
 548            skip frozen nodes. That is valid because the per-node losses
 549            are independent. ``None`` (default) computes every node.
 550        vc_ehat : dict[str, dict[str, Tensor]] | None, optional

 552            ``{node: {on: e_hat}}``. ``fit`` passes the frozen

 558        -------
 559        dict[str, Tensor]
 560            One log-likelihood tensor per node, each shape ``(n,)``.
 561        """
 562        feats = self._features(values)
 563        n = next(iter(values.values())).shape[0]
 564        out = {}
 565        for name in self.order if nodes is None else nodes:
 566            node = self.nodes[name]
 567            ehat = (
 568                vc_ehat.get(name)
 569                if vc_ehat is not None
 570                else self._vc_ehat_live(node, values, n)

 745    def _fit_epoch(
 746        self,
 747        train_vals: dict[str, Tensor],
 748        prev_acc: dict[str, float],
 749        frozen: set[str],
 750        opt: torch.optim.Optimizer,
 751        batch_size: int,
 752        vc_ehat_train: dict[str, dict[str, Tensor]] | None,
 753        vc_penalized: dict[str, list],
 754    ) -> dict[str, float]:
 755        """Run one epoch of minibatch training over the non-frozen nodes.
 756
 757        Returns the epoch-mean train NLL per node; a frozen node carries
 758        its last computed value forward. The VC penalty joins the loss but
 759        never the returned NLLs.
 760        """
 761        active = [name for name in self.order if name not in frozen]
 762        n = len(next(iter(train_vals.values())))
 763        perm = torch.randperm(n, device=self.device)
 764        acc = dict.fromkeys(active, 0.0)
 765        for start in range(0, n, batch_size):
 766            idx = perm[start : start + batch_size]
 767            batch = {k: v[idx] for k, v in train_vals.items()}
 768            per_node = self.node_log_prob(
 769                batch, nodes=active, vc_ehat=_slice_ehat(vc_ehat_train, idx)
 770            )
 771            node_nlls = {k: -v.mean() for k, v in per_node.items()}
 772            loss = torch.stack(list(node_nlls.values())).sum()
 773            for name in active:  # VC penalty joins the loss (never the history)
 774                for m in vc_penalized[name]:
 775                    loss = loss + m.penalty * m.l2() / n
 776            opt.zero_grad()
 777            loss.backward()
 778            opt.step()
 779            w = len(idx) / n
 780            for k, v in node_nlls.items():
 781                acc[k] += float(v.detach()) * w
 782        return {
 783            name: acc.get(name, prev_acc.get(name, float("nan"))) for name in self.order
 784        }

 882            ``None`` (default) keeps the learning rate constant, so a fit is
 883            reproducible from the rate and the budget alone; the measured
 884            recommendation for everyday fits is ``"plateau"``
 885            (``docs/training-speed.md``).
 886            ``"plateau"`` decays **per node**: when the validation NLL of
 887            a node did not improve by ``min_delta`` for
 888            ``plateau_patience`` epochs, its learning rate decreases by
 889            ``plateau_factor``, with floor ``1e-3 * learning_rate``.
 890        plateau_patience : int, optional
 891            Epochs without improvement before one plateau decay step, by
 892            default 30 — the value ``docs/training-speed.md`` recommends
 893            after measuring it against the hand-tuned two-phase schedule.
 894        freeze_patience : int | None, optional
 895            If set, a node whose validation NLL did not improve by
 896            ``min_delta`` for this many epochs is **frozen** — excluded
 897            from the loss and the backward pass. This is a real compute
 898            saving, because the per-node losses are independent. When
 899            every node is frozen the fit returns early. Freeze epochs are
 900            recorded in ``history["frozen"]``. Under ``schedule="plateau"``
 901            a node freezes only after its learning rate decayed to
 902            ``1e-2 * learning_rate`` or below.
 903        min_delta : float, optional
 904            Smallest validation improvement that counts, by default 1e-4 —
 905            an order of magnitude below the +1e-3/+5e-3 NLL tolerances any
 906            check in this repo applies, so it cannot mask a difference
 907            anyone measures.
 908        marginal_init : bool, optional
 909            If True, calibrate the intercept of each *unconditional* node
 910            to its marginal at initialization, instead of zuko's default
 911            zero initialization. A Bernstein continuous node gets the
 912            linear map of the pre-scaled domain onto the standard-logistic
 913            5%/95% quantiles (the default is about 2.5x too steep). An
 914            ordinal node gets cutpoints at the empirical class log-odds
 915            (the default zeros are near-uniform). This is a pure
 916            initialization: the converged MLE is unchanged. Applied on the
 917            first fit only. Affects only ``SimpleIntercept`` nodes;
 918            conditional ``ci`` intercepts stay untouched. Default False.
 919        vc_warm_start : bool, optional
 920            If True (default), the ``beta0`` of each ``VC`` term is
 921            initialized from the classical all-``ls`` solution of its
 922            node's conditional (deterministic L-BFGS on a throwaway
 923            proxy). The penalized head then starts at the classical answer
 924            and only learns deviations. Applied once per term — a buffer
 925            that survives ``save``/``load`` guards against re-runs. Does
 926            nothing without VC terms.
 927        plateau_factor : float, optional
 928            Multiplier of one per-node plateau decay step, by default 0.3.
 929            Gentler than torch's own ``ReduceLROnPlateau`` (0.1), which
 930            matters here because the decay is per node off a noisy per-node
 931            validation curve: three 0.3 steps land near one 0.1 step, but a
 932            single spurious plateau costs a third of the rate instead of a
 933            tenth. Read only under ``schedule="plateau"``.
 934        vc_oof_fit : dict | None, optional
 935            Keyword overrides for the stage-1 out-of-fold proxy fits of
 936            centered VC terms, merged over the default
 937            ``{"epochs": 300, "learning_rate": 1e-2, "batch_size": 512}``.
 938            Nothing in this repo measures those three numbers; they are the
 939            pre-0.4 values, kept so centered fits stay comparable. They set
 940            the quality of ``e_hat``, which is what the centering buys, so
 941            override them if stage 1 underfits.
 942            Ignored when the treatment node is all-``ls`` — the
 943            deterministic :meth:`fit_classical` runs instead.
 944
 945        Returns
 946        -------
 947        CausalFlowDAG
 948            ``self``, fitted.
 949
 950        Raises
 951        ------
 952        ValueError
 953            If ``epochs`` is not given, or if ``schedule`` is neither
 954            ``None`` nor ``"plateau"``.
 955
 956        Notes
 957        -----
 958        For ``VC`` terms the objective is the **penalized** NLL on the
 959        total-likelihood scale. Each term adds
 960        ``penalty * ||b_theta weights||^2`` to the summed NLL, that is
 961        ``penalty * ||w||^2 / n_train`` to the mean loss. This is a fixed
 962        Gaussian prior: the shrinkage vanishes as n grows, the classical
 963        penalized-likelihood convention. ``beta0`` is not penalized. The
 964        recorded ``history`` NLLs stay pure likelihoods. After training,
 965        each ``b_theta`` is re-centered to mean zero over the training
 966        data. That preserves the function: the constant moves into
 967        ``beta0``.
 968
 969        ``VC(center=...)`` terms run a stage-1 out-of-fold propensity
 970        computation before the loop (:meth:`_vc_oof_stage`). The training
 971        loss uses those frozen out-of-fold values. The epoch-level
 972        validation monitor, and every post-fit query, uses the live
 973        full-fit treatment node.
 974        """
 975        if epochs is None:
 976            raise ValueError(
 977                "fit() needs epochs=. There is no default budget: a fixed one "
 978                "over-spends on some workloads and under-spends on others "
 979                "(docs/training-speed.md). Set a budget, or a generous one "
 980                "with schedule='plateau' and freeze_patience= to stop early."
 981            )
 982        if schedule not in (None, "plateau"):
 983            raise ValueError(f"unknown schedule {schedule!r}")
 984        if seed is not None:
 985            torch.manual_seed(seed)
 986        self._set_ranges(train_df, marginal_init=marginal_init)
 987        if vc_warm_start:
 988            self._vc_warm_start(train_df)
 989        vc_penalized = self._vc_penalized()
 990        # stage 1 for centered VC terms (issue #30): frozen OUT-OF-FOLD e_hat
 991        # for the training rows — a plain tensor, so the Y-node loss has no
 992        # gradient path into the treatment node (per-node factorization intact).
 993        vc_ehat_train = self._vc_oof_stage(train_df, vc_oof_fit)
 994
 995        train_vals = self._tensorize(train_df)
 996        val_vals = self._tensorize(val_df) if val_df is not None else train_vals
 997
 998        opt = self._make_optimizer(learning_rate)
 999        best = self._best_store(restore_best)
1000        sched = _FitSchedule(
1001            self.order,
1002            schedule,
1003            learning_rate,
1004            plateau_patience,
1005            plateau_factor,
1006            freeze_patience,
1007            min_delta,
1008        )
1009        t0 = time.perf_counter()
1010        t_offset = self.history["time"][-1] if self.history.get("time") else 0.0
1011        train_acc: dict[str, float] = {}
1012
1013        for epoch in range(epochs):
1014            self.train()
1015            train_acc = self._fit_epoch(
1016                train_vals,
1017                train_acc,
1018                sched.frozen,
1019                opt,
1020                batch_size,
1021                vc_ehat_train,
1022                vc_penalized,
1023            )
1024            self.eval()
1025            if self._end_epoch(
1026                opt=opt,
1027                sched=sched,
1028                best=best,
1029                verbose=verbose,
1030                epoch=epoch,
1031                epochs=epochs,
1032                train_acc=train_acc,
1033                val_vals=val_vals,
1034                t_start=(t0, t_offset),
1035            ):
1036                break
1037
1038        if best is not None:  # restore per-node best-validation weights
1039            self._load_best_weights(best)
1040        self._recenter_vc(train_vals)
1041        self.eval()
1042        return self

1085    def _vc_warm_start(self, train_df: pd.DataFrame) -> None:
1086        """Initialize every VC term's ``beta0`` from the classical solution.
1087
1088        The value comes from the all-``ls`` solution of the node's conditional.
1089        Issue #28 recommends this warm start.
1090
1091        A throwaway proxy of the node (same kind/transform, every parent an LS
1092        term, parent marginals irrelevant to the conditional because the joint
1093        NLL decomposes per node) is fitted with the deterministic
1094        :meth:`fit_classical`, and the ``on`` coefficient copied into ``beta0``
1095        (for a binary ordinal treatment, the identified one-hot difference
1096        ``w[1] - w[0]``). ``b_theta`` already starts at the zero function
1097        (zero-initialized output layer). Runs once per term — the
1098        ``warm_started`` buffer survives ``save``/``load``.
1099        """
1100        for name in self.order:
1101            nd = self.nodes[name]
1102            todo = [g for g in nd._vc_groups if not bool(nd.shifts[g[0]].warm_started)]
1103            if not todo:
1104                continue
1105            proxy = CausalFlowDAG(self._ls_proxy_spec(name), device=str(self.device))
1106            proxy.fit_classical(train_df[[*nd.parents, name]], verbose=False)
1107            for g in todo:
1108                w = proxy.nodes[name].shifts[g.on].weight.detach()
1109                b0 = float(w[-1] - w[0]) if g.on_is_ord else float(w[0])
1110                m = nd.shifts[g.on]
1111                with torch.no_grad():
1112                    m.beta0.fill_(b0)
1113                m.warm_started.fill_(True)

1126    def _vc_oof_stage(
1127        self, train_df: pd.DataFrame, vc_oof_fit: dict | None = None
1128    ) -> dict[str, dict[str, Tensor]] | None:
1129        """Compute stage 1 of the two-stage centered-VC design, issue #30.
1130
1131        The result holds the frozen training-time propensities, as
1132        ``{node: {on: (n,) tensor}}``.
1133
1134        The values are **out-of-fold** — K refits of the treatment node
1135        only, each predicting its held-out fold (the DML cross-fitting
1136        requirement; in-sample e_hat reintroduces the own-observation bias
1137        and can be worse than no centering). Bookkeeping lands in
1138        ``self.vc_center_info[(node, on)]`` (``e_oof``, ``fold_id``,
1139        ``folds``, ``n``) so tests can assert the fold structure — a later
1140        "simplification" to in-sample e_hat fails CI.
1141        """
1142        jobs = [
1143            (name, g)
1144            for name in self.order
1145            for g in self.nodes[name]._vc_groups
1146            if g.center
1147        ]
1148        if not jobs:
1149            return None
1150        self.vc_center_info = {}
1151        np_dtype = self._np_dtype
1152        out: dict[str, dict[str, Tensor]] = {}
1153        rng_state = torch.get_rng_state()  # proxies reseed; keep fit reproducible
1154        try:
1155            for name, g in jobs:
1156                e, fold_id = self._vc_oof_propensity(
1157                    g.on, train_df, g.folds, vc_oof_fit
1158                )
1159                out.setdefault(name, {})[g.on] = torch.as_tensor(
1160                    e.astype(np_dtype), device=self.device
1161                )
1162                self.vc_center_info[(name, g.on)] = {
1163                    "folds": int(g.folds),
1164                    "fold_id": fold_id,
1165                    "e_oof": e.copy(),
1166                    "n": len(train_df),
1167                }
1168        finally:
1169            torch.set_rng_state(rng_state)
1170        return out

1172    def _vc_oof_propensity(
1173        self, on: str, train_df: pd.DataFrame, k: int, vc_oof_fit: dict | None = None
1174    ) -> tuple[np.ndarray, np.ndarray]:
1175        """Compute the out-of-fold ``P(on=1|pa_on)``.
1176
1177        The function refits the ``on`` node K times, and only that node. Each
1178        refit uses a single-node proxy whose parents are sources, because their
1179        marginals cannot influence the conditional. Each refit then predicts the
1180        fold it never saw.
1181
1182        A treatment with all-``ls`` terms uses :meth:`fit_classical`, which is
1183        deterministic and takes seconds. Any other treatment uses a
1184        fixed-budget Adam fit — ``vc_oof_fit`` overrides its keywords, see
1185        :meth:`fit`.
1186        """
1187        on_nd = self.nodes[on]
1188        if any(g.center for g in on_nd._vc_groups):
1189            raise NotImplementedError(
1190                f"treatment node {on!r} itself has a centered VC term. "
1191                "Chained centering is not supported."
1192            )
1193        node_spec = self.spec[on]
1194        proxy_spec = self._source_proxies(on_nd.parents)
1195        terms = node_terms(node_spec)
1196        proxy_spec[on] = OrdinalNode(2, terms)
1197        all_ls = all(map(_covered_by_classical, terms))
1198        cols = [*on_nd.parents, on]
1199
1200        n = len(train_df)
1201        fold_id = np.random.default_rng(0).permutation(n) % k
1202        e = np.empty(n, dtype=np.float64)
1203        for j in range(k):
1204            proxy = CausalFlowDAG(proxy_spec, device=str(self.device), seed=0)
1205            held_in = train_df.iloc[fold_id != j][cols]
1206            if all_ls:
1207                proxy.fit_classical(held_in, verbose=False)
1208            else:
1209                fit_kw = {"epochs": 300, "learning_rate": 1e-2, "batch_size": 512}
1210                fit_kw.update(vc_oof_fit or {})
1211                proxy.fit(held_in, verbose=0, seed=0, restore_best=False, **fit_kw)
1212            e[fold_id == j] = proxy._predict_p1(on, train_df.iloc[fold_id == j])
1213        return e, fold_id

1232    @torch.no_grad()
1233    def varying_coef(
1234        self, node: str, data: pd.DataFrame, t: str | None = None
1235    ) -> np.ndarray:
1236        """Evaluate the fitted effect function ``beta(x)`` of a ``VC`` term.
1237
1238        This is the first-class read-out of issue #28. The value comes in
1239        closed form from the fitted term, as ``beta0 + b_theta(modifiers)``.
1240        It is deterministic and needs no abduction. It is free of ``y``,
1241        because only the modifier columns of ``data`` are read. For a binary
1242        treatment it is identical to the abduction difference
1243        ``u(x, t=1, y) - u(x, t=0, y)``.
1244
1245        The value lives on the latent, log-odds scale of the node. A
1246        continuous node adds it. An ordinal node subtracts it from the
1247        cutpoints.
1248
1249        For a centered term (``center=...``) the form of the returned
1250        ``beta`` does not change. ``beta0`` then reads as the effect at the
1251        treatment margin, which is the observed propensities.
1252
1253        Parameters
1254        ----------
1255        node : str
1256            Name of the node that carries the VC term.
1257        data : pd.DataFrame
1258            Rows at which to evaluate ``beta``. Must contain every modifier
1259            column of the term.
1260        t : str | None, optional
1261            Treatment name of the VC term. Optional when the node has
1262            exactly one VC term.
1263
1264        Returns
1265        -------
1266        np.ndarray
1267            The ``beta`` values, shape ``(n,)``. Constant when the term has
1268            no modifiers.
1269
1270        Raises
1271        ------
1272        KeyError
1273            If ``node`` is unknown, if the node has no VC term on ``t``, or
1274            if a modifier column is missing from ``data``.
1275        ValueError
1276            If the node has no VC term, or if ``t`` is omitted while the
1277            node has several VC terms.
1278        """
1279        nd = self._node(node)
1280        vcs = {g.on: g.mods for g in nd._vc_groups}
1281        if not vcs:
1282            raise ValueError(f"node {node!r} has no VC term.")
1283        if t is None:
1284            if len(vcs) > 1:
1285                raise ValueError(
1286                    f"node {node!r} has several VC terms ({sorted(vcs)}). "
1287                    "Pass t=<treatment name>."
1288                )
1289            t = next(iter(vcs))
1290        if t not in vcs:
1291            raise KeyError(
1292                f"node {node!r} has no VC term on {t!r} (has {sorted(vcs)})."
1293            )
1294        mods = vcs[t]
1295        mod_feat = None
1296        if mods:
1297            feats = self._features(self._tensorize(data, mods))
1298            mod_feat = torch.cat([feats[p] for p in mods], dim=1)
1299        return nd.shifts[t].beta(mod_feat, len(data)).cpu().numpy()

1358    @torch.no_grad()
1359    def intercept_contributions(self, node: str, data: pd.DataFrame) -> dict:
1360        """Decompose a complex intercept into mean-centered per-term parts.
1361
1362        The parts are contributions to the transform parameters of the node.
1363        Use them to plot additive partial effects.
1364
1365        An additive complex intercept,
1366        ``CI("x1", "x2", allow_interaction=False)``, builds one
1367        network per ``I`` term and **sums their outputs in unconstrained
1368        parameter space**: ``theta(pa) = net_1(x1) + net_2(x2)``. The sum is
1369        identified, so every L1/L2/L3 query is correct. Each term's output,
1370        however, is identified only up to a constant — a constant moves
1371        freely between the nets. The *raw* per-term outputs are therefore
1372        not directly comparable.
1373
1374        This method resolves the ambiguity with the usual additive-model
1375        (GAM) convention: a **sum-to-zero (mean-centering) constraint over
1376        the rows of** ``data``. Each term's contribution is centered to mean
1377        zero per parameter. The removed constants collect into a single
1378        ``baseline``. The decomposition is exact:
1379
1380            ``theta(pa) = baseline + sum_terms contribution_term(pa)``
1381
1382        ``baseline`` plus the uncentered row sum of the contributions
1383        reproduces the model's transform parameters. This is **post-hoc
1384        only**: it reads the fitted weights and changes nothing about the
1385        model or any frozen number (issue #20, Option A). Shift terms
1386        (``LS``/``CS``) are a separate, already-interpretable slot — see
1387        :meth:`ls_coefficients`.
1388
1389        Parameters
1390        ----------
1391        node : str
1392            Name of a node with at least one complex-intercept (``I``) term
1393            that has parents.
1394        data : pd.DataFrame
1395            Rows over which to center and at which to evaluate the
1396            contributions. Must contain every intercept-parent column.
1397
1398        Returns
1399        -------
1400        dict
1401            Three keys. ``"baseline"`` is the absorbed constant, a ``(P,)``
1402            array — the sum of the per-term means. ``P`` is the node's
1403            transform-parameter count: ``ut.n_params`` for a continuous
1404            node, ``levels - 1`` cutpoint parameters for an ordinal node.
1405            ``"contributions"`` is ``{term_label: (n, P) array}`` — each
1406            term's mean-centered contribution at each row, columns summing
1407            to about zero over the rows. ``term_label`` is the term's
1408            parents joined by ``"+"``. ``"parents"`` is
1409            ``{term_label: tuple(parent_names)}``.
1410
1411        Raises
1412        ------
1413        KeyError
1414            If ``node`` is unknown, or if an intercept-parent column is
1415            missing from ``data``.
1416        ValueError
1417            If the node has no complex-intercept term with parents.
1418
1419        Notes
1420        -----
1421        The contributions live in the transform's **unconstrained**
1422        parameter space, where the model sums the additive terms before the
1423        monotonicity constraint. They are exact partial effects on those
1424        parameters, but not, in general, an additive shift of the curve
1425        itself.
1426        """
1427        nd = self._node(node)
1428        groups = nd._intercept_groups
1429        if not groups:
1430            raise ValueError(

1439        # one net per group: the additive case stores them in intercept_nets;
1440        # a single (possibly joint) I-term is the lone `intercept` network.
1441        nets = (
1442            list(nd.intercept_nets) if nd.intercept_nets is not None else [nd.intercept]

1446        parents: dict[str, tuple] = {}

1450            mean = raw.mean(dim=0, keepdim=True)  # (1, P)
1451            label = "+".join(grp)
1452            contributions[label] = (raw - mean).cpu().numpy()

1454            baseline = mean if baseline is None else baseline + mean

1456            "baseline": baseline.cpu().numpy().ravel(),

1458            "parents": parents,

1504    def fit_classical(
1505        self,
1506        train_df: pd.DataFrame,
1507        *,
1508        max_iter: int = 400,
1509        tol: float = 1e-6,
1510        chunk: int = 25,
1511        history_size: int = 50,
1512        verbose: bool = True,
1513    ) -> dict:
1514        """Fit an all-``ls`` model the classical way.
1515
1516        The fit uses full batches, float64, and L-BFGS with a strong-Wolfe
1517        line search. There are no minibatches, no schedule and no early
1518        stopping, so the fit is deterministic and bit-reproducible. It lands
1519        on the exact maximum-likelihood estimate and matches classical
1520        software, that is ``statsmodels`` ``OrderedModel`` and R ``polr`` or
1521        ``Colr``. It is much faster than minibatch Adam.
1522
1523        This method is valid only when every edge is ``ls``, because each
1524        node-conditional is then a classical transformation model. Any other
1525        model raises. For a ``cs`` or ``ci`` model use :meth:`fit`, where
1526        the minibatch noise also regularizes the MLPs.
1527
1528        Parameters
1529        ----------
1530        train_df : pd.DataFrame
1531            Training data, one column per node.
1532        max_iter : int, optional
1533            Upper limit on L-BFGS iterations, by default 400.
1534        tol : float, optional
1535            Relative NLL change between L-BFGS rounds that counts as
1536            converged, by default 1e-6.
1537        chunk : int, optional
1538            Inner L-BFGS iterations per round, by default 25. Convergence
1539            is checked between rounds.
1540        history_size : int, optional
1541            L-BFGS memory, by default 50.
1542        verbose : bool, optional
1543            Print a one-line summary, by default True.
1544
1545        Returns
1546        -------
1547        dict
1548            A convergence report: ``converged``, ``n_iter``, ``final_nll``,
1549            ``grad_norm``, ``seconds``, and the fitted ``coefficients``
1550            from :meth:`ls_coefficients`.
1551
1552        Raises
1553        ------
1554        ValueError
1555            If the spec has ``cs``, ``ci`` or ``vc`` terms.
1556
1557        Notes
1558        -----
1559        float64 is a transient compute mode. The model is upcast for the
1560        fit, and ``self.double()`` converts the parameters and the range
1561        buffers of the transforms in one call. Afterwards the model returns
1562        to float32, so the stored model and ``save``/``load`` stay float32.
1563        Double precision is what lets the line search resolve the optimum
1564        cleanly.
1565
1566        Convergence is judged by **NLL flatness**: a relative change below
1567        ``tol`` between L-BFGS rounds. ``|grad|`` and individual
1568        coefficients do *not* settle to machine precision. A continuous
1569        node's Bernstein intercept, and weakly-identified directions such
1570        as rare one-hot levels or a flat treatment-effect ridge, keep
1571        drifting along near-zero-curvature valleys long after the
1572        likelihood and the well-identified coefficients reach the MLE.
1573        Correctness is therefore verified by comparison to classical
1574        software (see ``experiments/misc/validate_ls.py``), not by this flag.
1575        """
1576        if not self._is_all_ls():
1577            raise ValueError(
1578                "fit_classical requires an all-`ls` spec, that is every edge "
1579                "term 'ls'. This spec has cs, ci or vc terms. Use fit() for "
1580                "flexible models."
1581            )
1582        self._set_ranges(train_df)
1583
1584        self.double()  # parameters + buffers (xmin/xmax) -> float64, one call
1585        t0 = time.perf_counter()
1586        # chunk: inner L-BFGS iterations per round; we stop on NLL change
1587        try:
1588            vals = self._tensorize(train_df)
1589            self.train()
1590            opt = torch.optim.LBFGS(
1591                self.parameters(),
1592                lr=1.0,
1593                max_iter=chunk,
1594                history_size=history_size,
1595                tolerance_grad=0.0,
1596                tolerance_change=0.0,
1597                line_search_fn="strong_wolfe",
1598            )
1599
1600            def closure():
1601                opt.zero_grad()
1602                nll = torch.stack(
1603                    [-lp.mean() for lp in self.node_log_prob(vals).values()]
1604                ).sum()
1605                nll.backward()
1606                return nll
1607
1608            prev_nll, final_nll, n_iter, converged = (
1609                float("inf"),
1610                float("nan"),
1611                0,
1612                False,
1613            )
1614            for _ in range(max(1, max_iter // chunk)):
1615                final_nll = float(opt.step(closure).detach())
1616                n_iter += chunk
1617                if abs(prev_nll - final_nll) < tol * (1.0 + abs(final_nll)):
1618                    converged = True
1619                    break
1620                prev_nll = final_nll
1621            grad_norm = float(
1622                torch.cat(
1623                    [
1624                        p.grad.reshape(-1)
1625                        for p in self.parameters()
1626                        if p.grad is not None
1627                    ]
1628                ).norm()
1629            )
1630            coefs = self.ls_coefficients()  # read while still float64
1631        finally:
1632            self.float()  # restore canonical float32 (lossy ~1e-7, harmless)
1633        self.eval()
1634
1635        report = {
1636            "converged": converged,
1637            "n_iter": n_iter,
1638            "final_nll": final_nll,
1639            "grad_norm": grad_norm,
1640            "seconds": time.perf_counter() - t0,
1641            "coefficients": coefs,
1642        }
1643        if verbose:
1644            logger.info(
1645                "fit_classical: %d L-BFGS iters, NLL %.6f, %.2fs%s",
1646                n_iter,
1647                final_nll,
1648                report["seconds"],
1649                "" if converged else f"  (NLL still moving at {max_iter} iters)",
1650            )
1651        return report
